## 修订后观感杠杆排序

1. **Light 暖纸主题成为桌面默认**（1.1+1.2 合并）：壁纸资产 + token 全组——
   一项改变 60% 观感。stella 的气质 = 浅色纸感，我们按 dark 调什么都不会像。
2. **左竖栏 dock 重设计**（2.1/2.2）：形态 + 线性图标资产 + 去常驻底色。
3. **窗口标题居中 + 阴影重校**（2.3/2.4）：小改，收益中等。
4. **内容卡片密度**（2.5）：跨层（示例主题），可后置或随 458。
5. **动效**（4.1）：形态稳定后收尾。
6. 顶部胶囊 tab（3.1）与桌面时钟卡（3.2）：功能映射裁定后再排。

## 用户已裁定（2026-09-01，全部三条 + 权威深色参照）

- 桌面画框：**不做**（全屏壳维持）。
- 三色圆点：**保留**（与权威参照一致）；标题改居中。
- **A 主题**：深浅**双主题可切换**（stella dark 实证：暖纸壁纸保持浅色不变，
  面板/窗转深蓝黑——**壁纸与主题解耦**；Settings 有 Dark Mode 开关）。
- **B dock**：位置设置可选（487 已有 position 配置），**先沿用底栏**；
  视觉按权威图精致化（去常驻 accent 底格、中性结构色、hover 才出格）。
- **C 顶部胶囊/桌面小组件**（时钟卡/日历卡等桌面直显组件）：**独立计划**
  （不在二期）。
- 新增映射：stella Settings 面板（Dark Mode/Wallpaper/Transparency 模糊
  强度/Notifications/Sound）≈ 487 设置面板的 Appearance 扩展方向；
  **Transparency（窗口透明度/模糊强度）= 503-P2 blur parity 决策的落点**
  （iced 无 backdrop-blur → 以窗口 alpha 分级实现，设置化）。
