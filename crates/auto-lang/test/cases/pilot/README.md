# Plan 768 pilot suite

Read-only import pilot for the AutoDown TestCase protocol (Design 35
phase A / Plan 768). 21 cases / 26 checks across the two live adapters:

- `avm/run` — real VM through the production path-carrying API
  (`run_with_capture_and_path`), same as the legacy `run_vm_file_test`;
- `a2r/emit` — real Rust emission through the production single-file and
  project APIs, byte-compared against oracles.

## Layout

- `pilot.suite.ad` — suite contract; `fixture_root: "../.."` points at
  `crates/auto-lang/test/`, so every legacy source/oracle is referenced IN
  PLACE (nothing is copied or moved; legacy wrappers stay untouched).
- `vm-basics.case.ad` (9 cases; 3 carry dual `vm` + `rust` checks),
  `vm-shortcircuit.case.ad` (3), `vm-script.case.ad` (1 `.as`),
  `a2r-basics.case.ad` (5), `a2r-cabi.case.ad` (2 manifest cases),
  `a2r-project.case.ad` (1 multi-artifact project emission).
- `oracle/` — NEW oracles created for this pilot (dual-check emissions and
  the project-mode snapshot). Each was generated by the runner's proposal
  flow and independently reviewed before acceptance; see
  `legacy-map.tsv` for per-case provenance.
- `legacy-map.tsv` — the import ledger: every legacy fixture consumed,
  its old entry/gate/comparator, the new case/check identity, and the
  classification (`imported`, `imported+dual`, `strengthened-oracle`,
  `unwired-revived`, `new-oracle`).

## Deliberately NOT imported (recorded, not silently dropped)

- `vm/99_script_err/*` — legacy wrappers are `#[cfg(feature = "python")]`;
  sources need `use.py` (no-default runs fail with "Python FFI not
  enabled"). Phase-B candidate with a python-enabled gate.
- `vm/17_modules/001_use_fn` — legacy wrapper `#[ignore]`d; `use
  auto.greet_mod` does not resolve through the production path (module not
  found). Stays out until module resolution for `auto.*` is wired.

## Regenerating the new oracles

`pilot_oracle_bootstrap` in `src/tests/test_cases_tests.rs` (ignored test)
reruns the suite and refreshes `oracle/` candidates via the proposal flow;
acceptance stays a deliberate review step.
