# 系统应用与 Demo

系统应用与 Demo 展示了 Auto 生态里的日常工具和具体交互：从待办、日历和媒体应用，到文件管理、启动器和小游戏。它们的功能与完成度不同，有些是桌面集成的应用，有些主要用于学习界面和应用结构。

[返回应用总览](/zh/apps) · [AutoOS 虚拟桌面](/zh/autoos/) · [AutoUI](/zh/ui)

## 先按用途认识应用

| 分类 | 可以从这些例子开始 | 了解什么 |
|---|---|---|
| 工作与生活 | 计算器、时钟、待办、日历、备忘录、天气 | 输入、筛选、日期选择与日常信息展示 |
| 阅读与交流 | 图书阅读器、博客阅读器、聊天 | 内容浏览、消息与阅读布局 |
| 媒体与创作 | 音乐、视频、相册、图片查看器、画板 | 媒体控制、文件资源与创作交互 |
| 系统与数据 | 文件管理器、启动器、系统监视器、日志、终端、配置、数据库 | 桌面入口、系统信息和数据工具 |
| 小游戏 | 俄罗斯方块、纸牌接龙、扫雷 | 键盘与指针交互、游戏状态和多窗口使用 |
| 应用结构示例 | 看板、RealWorld、图表 | 任务流、路由、前后端与数据展示 |

这里的分类用于认识应用，不表示表中每项都已达到相同的产品完成度，也不表示它们都可以直接在网站中运行。开发示例清单、桌面集成清单和桌面图标包含不同范围，不用一个固定数字代替各自的状态。

## 怎样查看它们

### 介绍与实际画面

应用介绍先说明用途和一两个典型操作，再配真实界面截图。这样即使应用需要本地文件、数据库或系统服务，访客也能在网站上读懂它。后续会逐项补充截图与运行条件。

目前可以先看 [虚拟桌面的实际工作场景](/zh/autoos/#desktop-showcase)：启动器、小游戏并排，以及编辑器、待办和日历的组合。桌面截图展示捕获时的实际画面，不替代每个功能的验证。

### 开发示例画廊

[现有应用示例画廊（共享入口）](/ui/demos/) 提供界面、源码和开发资料，适合进一步了解示例结构。部分示例需要后台、宿主能力或外部资源；页面能够挂载并不表示所有操作都能在纯静态部署中完成。

画廊和本页承担不同用途：本页帮助选择和理解应用，画廊帮助研究界面及其实现。这里只提供独立入口，不在介绍页自动装载整套运行视口。

### 在线体验与本地运行

后续只有在无后台部署下验证通过的应用，才提供对应的“在线体验”入口。需要文件系统、终端、真实监测、数据库或模型服务的操作，则说明本地运行条件。

对于少量需要服务、但值得直接演示交互的应用，可以考虑独立的演示数据版本。它应明确标注数据来源、重置方式和保存范围；演示数据的操作效果与真实服务能力分别介绍。
