# AutoGraphics、AutoForge 与承载游戏：v0.6 阶段设计

> 2026-10-16；目标态草案。本轮只整理设计，未实施。阶段目标是待选择的候选，不是全部新增为发布门禁，也不决定下一条实施路线。
> 来源：AutoOS《3D引擎方案比较》后续讨论；继承[第三代互联网战略](thirdgen-internet-strategy.md)，版本范围见[总体矩阵](../../roadmap-v0.6.md#7-v06路线阶段与拆分边界矩阵2026-10-16)。

## 1. 定位与已有材料

AutoGraphics 提供 UI、2D、3D 的场景与组合能力；AutoForge 是以运行中的产品为主要操作对象的创造应用。AutoMusk 继续承担通用对话式 Agent，AutoEdit 保持轻量编辑器定位，不因新创造工具合并产品。

早期 Godot/GDScript 路线及已有 demo 是参考资产。后续讨论提出 Auto 自有语义层、Surface/Portal 组合，以及直接使用 wgpu 等底层库的方向；具体依赖版本、共享设备和平台能力仍需探针，本文不把对话中的库特性断言当成本地验证结论。
现有 `forge/` 文档和 auto-musk 的历史 Forge 拆分设计描述旧 Agent，不证明新的产品创造应用已经存在；旧仓保全与新产品建仓另定 Plan。

## 2. 设计边界

- 公共概念候选为 World/Node、Space、View、Surface、Portal、资源与输入路由；各自身份、所有权、更新时间、坐标系和销毁规则先于引擎绑定。
- Auto 拥有场景与组合语义；底层渲染、物理、动画、字体和模型加载通过 adapter 复用库。公共资源 ID 不直接采用某个引擎的对象指针。
- 独立原型可以手工构造场景模型；这只验证图形核心，不证明 Auto 源码前端或 AutoUI 已接通。声明语法/lowering 后续消费语言 SDK，不把场景关键字塞回 core AST。
- 共享 GPU、UI 纹理、Portal 输入和递归组合是需验证的接缝；先限制组合深度、检测循环、明确帧同步和释放，不承诺任意递归。
- AutoForge 的选择对象需要稳定身份与修订号，修改须经预览/应用/失败恢复。操作日志记录任务、变更和结果；尚未完成的任务可观察和取消，不能把动画效果当作真实执行进度。

## 3. v0.6 阶段目标与验收

| 子线 | 本版候选终点 | 可验收成果与失败判据 |
|---|---|---|
| AutoGraphics 核心 | 技术原型 | 独立宿主真实绘制一个 2D 场景和一个 3D 场景；至少两个 Surface 内容不同且独立更新；固定场景/窗口/DPI记录帧时、内存与关闭后资源；输入只送目标 Surface，销毁后不再更新 |
| 组合接缝 | 调研＋有限原型 | 先用独立测试 Surface 验证纹理组合、深度上限/循环拒绝和坐标映射；再以一个真实 AutoUI Surface 验证共享设备或替代方案。后一项依赖 UI adapter，未通过时只能称独立图形原型，不能称统一引擎已成立 |
| AutoForge | 交互原型，条件满足后展示 demo | 查看/单选/区域选择三模式；选中对象提出一次修改，看到实际结果、执行状态与 creation log；回退后模型及画面一致。使用模拟执行器必须标明；真实 demo 另验 Agent→代码/模型变更→重载全链 |
| 承载游戏 | 设计＋规则原型 | 国风种田/资源与战斗、装备/符箓形成一份小闭环规则；可用无图形模拟验证状态转移和资源收支。完整游戏、动作内容量和商业质量不列为本版门槛 |

首个实施 Plan 需固定目标平台、库版本、场景规模、帧时/内存预算和输入序列；本轮不编造性能成绩。先做能淘汰错误方案的组合实验，之后再决定展示内容与生产引擎投入。

## 4. 依赖与拆分边界

独立图形/资源原型不等待 AC/AAC 或三仓搬迁；只依赖选定的 GPU/窗口库。物理/动画 adapter 可独立验证，运行时 AutoABI 接口需消费对应版本合同。

真实 AutoUI 融合依赖 Design37 的 renderer/宿主所有权、稳定 SDK 和输入/生命周期接口；涉及 iced patch、UI native、VNode/VTree 或 RenderQueue 的改动归拆分协调线。AutoForge 的实际组件选取与源映射依赖 DevTools adapter，完整创造闭环还依赖 Agent、构建与重载服务。
不修改正在迁移的 UI 核心来便利原型，不复制 VTree、类型系统或包管理器。独立原型验收与集成验收分别出证据。

## 5. 本版不承诺与待决事项

完整分层编辑器、任意 UI/3D 递归、XR/网络世界、成熟游戏、完整物理/动画工具链不自动进入 v0.6。Godot 保留架构参考/可选实验后端位置，不据本稿删除 a2gd、旧 demo、旧仓或历史资产。
待选路线后决定第一宿主、场景交换模型、共享设备方式、首个真实修改任务与游戏原型范围。
