## 拟定自有玩法分母（待冻结审查）

两关各有三个固定收集物、入口和终点；单次触敌/触危险区/掉出界失败；获胜与失败后 Enter 建立新局，恢复位置、物品、敌人和计数。没有射击、斜坡、移动平台或二段跳。状态由 Auto 拥有；未来检查真实 Auto 状态、画面和声音。以下是拟定规则而非原作行为。

| ID | 输入、状态与预期 | 未来可区分反例 |
|---|---|---|
| G2-01 | 左右按键驱动水平运动，松开停止 | 松开仍漂移，反向仍朝原方向 |
| G2-02 | 落地按跳跃向上一次；空中再次按不跳；重力回落 | 按住连续起跳、空中额外跳 |
| G2-03 | 平台、墙、顶限制移动；接地允许下次跳；坑下界失败 | 穿墙/顶/地，离地仍判落地 |
| G2-04 | 三金币首次触碰各加 1 并消失 | 同一物品多次加分、重开未复原 |
| G2-05 | 一敌人在固定左右端点巡逻，触碰角色失败 | 穿过端点或触碰未失败 |
| G2-06 | 集齐后触终点胜利；未集齐继续；结束后 Enter 重开 | 缺币获胜、重开继承计数 |
| G2-07 | 相机跟随角色并限制在关卡矩形 | 离开边界或完全不跟随 |
| G2-08 | 精灵静止/行走/上升/下降对应状态，方向对应移动 | 空中行走帧、方向相反 |
| G2-09 | 跳跃与收集各一次音效；HUD 显示 0..3 与结束态 | 单事件重复播放、HUD 与计数不一致 |
| G3-01 | 前后左右相对于相机水平朝向行走；对角归一；角色朝向运动方向 | 环绕后仍沿世界轴、对角更快 |
| G3-02 | 落地按跳向上一次，空中无二段跳；重力落地 | 空中重复跳、平台下穿 |
| G3-03 | 固定立体平台约束墙顶地面；危险区或越界失败 | 侧面/落地穿透、危险触碰不失败 |
| G3-04 | 三金币首次触碰各加 1 并消失；未集齐不能终点获胜 | 同一金币多次加分、缺币获胜 |
| G3-05 | 危险/越界失败，集齐抵终点胜利；Enter 新局 | 新局继承计数或位置 |
| G3-06 | 跟随相机可环绕和缩放，距离有限且夹角受约束 | 操作无效、越界翻转或距离非有限 |
| G3-07 | 低多边形平台、角色、金币、终点可识别；idle/walk/jump 对应状态 | 模型不可见、运动仍静止 |
| G3-08 | 跳跃/落地/收集音效对应事件，HUD 显示计数和结束态 | 事件重复播放、HUD 与状态不同步 |

失败流程：移动→碰敌/危险或越界→失败→Enter→入口、计数 0、全部物品和敌人复位。获胜流程：收集三个不同物品→终点→胜利→Enter→同一初始状态。关卡坐标、具体输入绑定、碰撞几何和素材闭包仍待冻结；此表未通过 AC-02。

## 已证实边界

`docs/specs/auto-graphics/behavior-api.md` 与 854 `experimental/autographics-auto-driver/api/behavior_v1.at` 给出节点查找、平移、显隐、离散 `ag_input_x/y`、`ag_toggle`、tick；拓扑固定，句柄仅在 Run 内有效。`behavior_motion_v5.at::ag_move_and_slide` 与 `bounded-motion-profile.md` 提供有限 AABB 平移、最多两次接触，不能当作完整角色控制。`scene-assets.md` 的静态 GLB 禁止 URI、纹理、动画和蒙皮；候选四个 Kenney GLB 均引用 `Textures/colormap.png`，角色有四条动画，原文件不能直接进入该接口。专用 Squash 音画不等于公开通用音频/HUD；相机矩阵不等于公开游戏相机。逐 G 分类、代码证据及生命周期负例尚待补齐。

## 候选关卡参数与验收入口（仍待与资源选择核对）

未来采用固定 60 Hz 逻辑步，世界坐标单位由 Auto 项目固定；按键上升沿仅消费一次，关卡状态为 Playing、Won、Failed，只有后两态的 Enter 可重开。重开先终止旧局、释放局内资源，再建立全新状态；持有的旧句柄不得操作新局。以下参数是自有规则，不取自参考实现。

2D 坐标 x 向右、y 向上：关卡边界 x=[0,30], y=[-4,12]；角色出生 (2,1)，半宽 0.4、半高 0.5；静态平台矩形 [0,8]×[-1,0]、[10,18]×[-1,0]、[20,30]×[-1,0]，另有顶部平台 [12,15]×[1,1.25]；两坑下界 y=-3；x=0/30 为墙、y=10 为顶；敌人于 x=11..17、y=0.5 以 1 单位/秒巡逻；三个金币中心 (4,1)、(13,2.25)、(24,1)，目标中心 (28,1)。水平速度 4 单位/秒、重力 20 单位/秒²、起跳速度 8 单位/秒，按地面接触决策跳跃；接触敌人立即失败。金币/目标使用确定的 0.5 半径触发区域，角色框与区域相交计触发。相机视区宽 12、高 8，中心跟随角色并夹到关卡矩形可显示区域；不要求完整 TileMap、动态平台或敌人攻击。

3D x/z 水平、y 向上：角色出生 (2,1,2)，半宽/深 0.4、半高 0.5；平台为 [0,8]×[-1,0]×[0,8]、[10,18]×[-1,0]×[0,8]、[20,28]×[-1,0]×[0,8]；下界 y=-4，危险区 [14,16]×[0,1]×[3,5]。三个金币中心 (4,1,4)、(12,1,2)、(24,1,4)，目标 (26,1,6)，触发区半径 0.5；水平速度 4、重力 20、起跳速度 8。相机以角色为目标，初始距离 8，距离夹在 [4,12]，俯仰夹在 [15°,75°]，鼠标拖动改变水平角/俯仰，滚轮改变距离；输入相对相机水平朝向，对角归一。摄像机遮挡处理不是此小关必需项。两关具备可抵达上述收集物的路线仍须以几何和真实执行探针确认；数字不等于已经实测通过。

对照：Godot 2D 原作玩家无敌、有射击、斜坡、移动平台和二段跳；本关一触失败、无上述扩展且增加集齐终点胜利。Kenney 原作有二段跳、坠落平台，本关删去并加入固定危险/明确获胜与重开；它是设计和资源参考，不是 Godot 项目逐项复刻。Godot 3D 作为 CharacterBody3D 比较，不纳入第四个游戏或作为必选运行素材。

未来按固定种子/步长分别驱动输入与无输入对照，采样实际 Auto 状态、屏幕内容和音频事件：覆盖正常到达、未集齐终点、重复收集、四边和顶碰撞、空中二次跳、敌人/危险和越界失败、胜利/失败新局、相机环绕/边界、动画转场以及一次事件仅一次音效。测试须检查对象真实身份与状态重置，不能仅检查日志或命令发出。上列几何、输入和结束状态仍要在正式 T-02 核查后定稿。

### 输入、帧与声音约定（候选）

2D 左/右为 A/D 或左右方向键，跳跃为空格；3D 前/后/左/右为 W/S/A/D 或方向键，空格跳，鼠标左键拖拽环绕、滚轮缩放。相反方向同时按时该轴为 0；失焦清空按键和拖拽；仅 Playing 接收移动/跳跃，结束态 Enter 新局，重复按键事件不能触发额外跳或沿用到新局。2D 面向随最后非零水平输入；idle/run/jump/fall 用地面和垂直速度判断。3D idle/walk/jump 对应速度及地面状态。音效分别在跳跃、收集（3D 加落地）事件边沿各播放一次；失败/获胜文本与 `n/3` 一起显示。音频设备失败必须显式报告，不得把未发声当通过。

几何静态必要条件：同高度单跳在无碰撞理想模型下飞行时间 2×8/20=0.8 秒、水平位移 3.2 单位，超过 2 单位平台间距；最大上升 8²/(2×20)=1.6 单位，2D 角色底部从 0 可越过上平台顶 1.25。该算式只排除显然不可达，不是碰撞数值实现、真实 Auto 或游戏试玩证据。
