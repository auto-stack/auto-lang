# OS 与 AI 介绍

> Status: active · 来源：PLAN-719 r2 · 技术栈：VitePress + Vue 3。

## 理念与现状

LaOS（Language as OS）是用 Auto 组织系统部件、适配不同生态与统一对外接口的实现理念。OS over OS 是它当前的产品视角：虚拟桌面与宿主桌面并行。AI + Lang + OS 是面向人的知识管理、工作生活的长期方向，三者连续而非互相替代。

宿主虚拟桌面是当前主要形态；复用现有内核形成独立 Linux/OpenHarmony 系统是未来方向；自有内核、语言底座自实现 native 是更长期研究。当前 Auto/Rust/生成代码与既有系统设施共同组成实现基础。接口与 UI 一致性是逐项实现和验证的目标，不作全平台兼容或像素全等承诺。

`auto-lang` 负责语言与框架，`auto-os` 负责桌面表面、应用组装与产品集成。桌面 Shell、AutoShell 命令接口、AutoTerm 终端基础设施分别说明。应用实际执行按声明与集成路径判断，编译壳不等同于全部 VM 应用已迁移。

AI 按应用/用户界面、Agent 工具、共享客户端、aaid 模型服务、提供商分层，配置服务支撑相关设置。模型通信和资源协调与命令/文件工具执行职责分开。已有模型接入和开发工具不写成完整个人知识体系或跨应用长期协作已交付。

## 页面职责与作者源

- `/os`：理念连续性、系统组成、三种形态、进展与长期方向。
- `/ai`：共享 AI 的原因、职责分层、已有接入、边界与长期方向。
- `/autoos/`：当前桌面、窗口/工作区/启动、应用与配置，复用完整真实截图序列。
- `/ui-desktop`：已有 Vue、VM/iced 和编译路径，各路径与平台覆盖分别说明。
- 首页仅 OS/AI 卡片摘要，v0.5 仅同步相关分层/现状/未来路线，其他发布材料保全。
- 两篇历史/展望长文：`/articles/autoos-history` 与 `/articles/auto-ai-history`。以上均有 `/zh` 镜像。

概括和架构层名由 `theme/data/os-ai-introduction.ts` 同源双语组织，`IntroductionFrame.vue` 及 OS/AI 包装组件呈现。正文使用作者维护的 Markdown，采用 VitePress 默认阅读布局，SSG 与 local search 可索引。头部是正文概要，不能成为第二套相矛盾的状态来源。

架构图显著标为关系示意，必须呈现宿主/内核及渲染/合成层，不作为真实运行输出。状态用文字表达并标资料时点；取消无依据的数字墙、无限模型与伪运行示例。真实桌面截图仍按 PLAN-720 的原图、捕获日、递进、放大与小组件前提契约展示。

## 历史文章与来源

四份文章用默认文档阅读宽度、H2/H3、目录与锚点。对应总览提供入口，文章返回总览、两文互链、语言切换保留主题。

叙事解释当时的问题、改变的原因、实现与证据、现状和未来，不以口号或日期清单代替解释。关键历史节点附近引用项目设计/提交/归档计划；注明资料截止日，区分历史验证与当前回归。不得把移动/归档日期当功能诞生日，把历史注释当当前架构，把编排阶段数当 Agent 数，把会话压缩当个人长期知识库。

公开引用落地时必须可访问且支持附近的主张。本地未发布记录保留在研究报告；网站改用公开等价材料并按该材料实际内容调整说明，记录替换理由，不能借可访问链接掩盖源内容差异。
