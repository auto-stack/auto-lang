# Tabs 组件族规格（PLAN-641）

> 状态：PLAN-641 沉淀；覆盖 `tabs` 复合组件形态词表、VM 折叠契约与三源同步纪律。

## variant 形态词表（SD-01）

`tabs` 根节点 `variant` 属性，两值词表：

| 值 | 结构契约 |
|---|---|
| `default`（缺省） | 按钮托盘形态——shadcn 默认观感（muted 托盘 + 激活浮起芯片）；VM(iced) 侧为按钮排 + `[label]` 选中标记（现状零回归） |
| `enclosed` | 连通形态——①激活 tab 与内容面板共享背景、无接缝；②非激活 tab 扁平等高 cell，仅背景色差（非按钮/浮起芯片）；③tab 条（muted 底）与内容区（background 底）层次分明。**连通的视觉锚点 = 边框**：每个 cell 自带 1px 边框（Vue `border border-border`；iced padding-reveal 外衬），激活 cell 底部开口（Vue `data-[state=active]:border-b-0`；iced padding-bottom 0），内容面板自带左/右/下边框、顶部开口（Vue `border border-t-0`；iced padding-reveal [0,1,1,1]）——激活 tab 从开口处融进面板 |

**装饰差异不入词表**（SD-02 治理规则）：Chrome 观感（激活 tab 顶部大圆角 +
留缝）与 JetBrains IDE 观感（直角 + 1px 竖分隔）是同一 `enclosed` 的装饰
参数，由既有 token 承载——Vue 端 `rounded-t-*` class、VM 端根 style 的
`effective_border_radius`（顶部圆角，底角恒 0 保连通）。新增 variant 取值
须 Vue/iced 双端同落 + gallery 示例覆盖（对齐 Plan 435 P2 variant/size/icon
词表注记）。

## VM(iced) 轨契约

**复合标签折叠**（`aura_view_builder::convert_tabs`，tracked/untracked 双臂
镜像）：`tabs` 根（+ `tab`/`tabs-trigger`/`tabs-content` 子件与
`tabs-list`/`tabslist`/`tabrow` 透明包装）折叠为有状态 `View::Tabs`。
此前 tabs 族落 unknown fallback → Column（VM 轨无 tabs）。

- **受控选中最小集**：selected 解析序 `active`（索引）→ `value`（索引或按
  trigger 值串匹配）→ `defaultvalue`/`default` → 0；越界钳制到末 tab。
  prop 值经 `resolve_expr_to_value` 解析——静态字面量与状态引用（`.store`
  字段）均穿透。
- **点击切换**：根 `onselect` 或首个 trigger `onclick` →
  `DynamicMessage::Typed{widget_name, event_name, args:[选中 tab 的 value
  字符串]}`（handler 契约：首参=值字符串，`on { .Select(t) -> { .state = t } }`
  直绑；details_onclick 运行时注参同款）。无绑定则点击不切换（受控语义，
  对齐 Vue 端受控 v-model）。
- **`convert_view_messages` 显式臂**：`on_select` 为 Arc 回调，按
  `IcedMessage::from_dynamic` 包装转换（此前落 `_ => Empty` 通配臂，VM live
  树 Tabs 整枝折空）。
- **iced 渲染臂**（`ui/iced/renderer.rs` Tabs arm）：default 原样保留；
  enclosed 用 theme token（Background/Secondary/Muted/Foreground/
  MutedForeground）+ 顶角半径 token；button 命中面样式透明化（覆盖 iced
  默认 primary 底色，保"非按钮"扁平观感）。

**线协议**：A2UI `Tabs` 节点增 `variant`（Option，缺省省略，向后兼容）；
`a2ui/import.rs` 折叠为 tabs 根 prop、`export.rs` round-trip。

## Vue 轨契约

- **schema**（`schema/aura.at` + `aura/schema.rs` 双源）：tabs root props
  `value`（state_ref → v-model）/`active`/`defaultvalue`/`variant`
  (`oneof:default,enclosed`)/`onselect`；iced 级别 `partial`（五表漂移围栏
  对账）。
- **registry 组件**（reka-ui）：Tabs 根 `variant` prop →
  `provide("autoTabsVariant")`；TabsList/TabsTrigger/TabsContent inject 切
  class 结构。**wrapper 必须渲染 `<slot />`**（自闭和丢子件为既有隐患，
  PLAN-641 顺修）；emits 必须 `defineEmits<TabsRootEmits>()` 类型化——空
  `defineEmits()` 使 `update:modelValue` 不转发、v-model 失联（046 实证）。

## 三源同步纪律（Q1 provenance 定案）

tabs SFC 存在**三份拷贝**，修改必须三处同步（互有差异点见下）：
