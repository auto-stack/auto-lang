### 1.2 产物与依赖承诺

- 单文件：`<stem>.a2r.rs`（`// Auto-generated by a2r transpiler` 头；需要时
  `use a2r_std::*;`）；`.rs.at` 层选时 `.a2r.rs.assembly.json`。
- 工程：`Cargo.toml`（name/version/edition 2021；`use.rs <crate>`→`x="*"`、
  `dep x(...)`→path/git/version）+ `main.rs` + 每模块 `.rs` + 目录 `mod.rs` + 源映射；
  `auto build` 形态由 CargoBuilder 补 auto-lang path 依赖与固定 axum/tokio/serde 版本。
- 运行时：`a2r-std`（http/fs/json/task/sqlite/redis/…）；数值 profile
  default-i64（默认）或 checked-i32；资源 profile plain/observe（998）。
- 版本身份：edition 2021；`v0.5` 是发布名而非代码版本（代码侧版本化身份只有上述
  四个 `legacy-a2r.*/1` profile id）。

## 2. 候选路由（本包交付：现役入口可选 ACE A2R）

- **选择开关**（auto-man 既有，PLAN-982）：`AUTO_ACE_RUST=ace`（或 `1/true/yes/a2r`）
  经注册渲染器走本仓宿主桥；未设/未知值保持 legacy，绝不静默切换；
  `AUTO_ACE_RUST_PROOF=<path>` 写 `{engine, a2r_dispatches, legacy_dispatches}`
  真实计数回执。
- **宿主桥升级（PLAN-1117 T-02）**：`auto-lang-ace-host::rust_transpile::
  transpile_scalar_source`（兄弟 CLI `auto rust`/`auto trans rust -m`/`auto build`
  ACE 臂绑定的渲染器名）改走**普通语言通道**——`ac.source.language.av/v1` 准入
  （+源含 `#{}` 时 CT 键）→ 实例化/CT 准备钩子（与 a2x-worker language 车道同一对
  共享 pass）→ `lower_language_program` → `assemble_language_file_set`
  （schema `auto.a2x.rust.language.fileset/1`）。标量前门仍可用
  （`transpile_with_profile(.., Scalar)`）。多模块包级渲染器
  （`transpile_package_rust`，packages 前门 RecordText 族）保持不动——语言面包
  车道为具名缺口（§5）。
- **构建车道升级**：m2-build 的 A2R build lane（`ac-build build --target a2r`）
  发射腿改走同一语言管线（session-less；a2c/a2py 车道不动），真 rustc 编译腿、
  SDK、仓外重定位、恢复沿 1116 冻结行为。
- **执行闭包**：候选产物执行闭包不含 AV、AutoVM、旧 AST emitter（ace workspace
  不依赖 legacy trans/VM crate——依赖级隔离）；兄弟 CLI 侧另有进程级
  `AUTO_ACE_RUST_PROOF` 计数回执。

## 3. 逐项映射（旧请求 → 新请求）

| 旧（legacy） | 新（候选） | 差异与归属 |
|---|---|---|
| `auto rust x.at` → `x.a2r.rs`（整程序、私有 main、i64 默认） | 同命令 + `AUTO_ACE_RUST=ace` → 三件套 `main.rs/a2x_runtime.rs/generated.rs` + manifest（`fn_main` pub、`value:<n>`/`trap:<Name>` 协议、checked i32） | 产物布局与观察协议变更为**候选身份**；兼容性由真实 Rust consumer 验证（V-01：`#[path]` 原样编入 + `fn_main()` 实调）。旧布局兼容=986 发行裁定 |
| `auto trans x.at rust --merge` → 单文件 merged | 同命令 + 开关 → `merge_fileset` 模块内联单文件（生成文本一字不改） | 同一三件套内联形态 |
| `auto build --render rust`（单文件） | 开关后 `rust/src/` 三件套（兄弟仓写盘） | CargoBuilder 侧 manifest 生成归 auto-man owner 接线 |
| 工程多模块（E-03 多文件） | 包级渲染器仍 RecordText 族 | **具名缺口**：语言面包车道（§5 D-1117-2） |
| `while` 条件循环 | 具名拒 `source.unsupported`（条件循环=`for <cond>`） | 语言面冻结差异；改写 `for x in a..b`（双通道同形） |
| for 裸列表字面量 scrutinee | 具名拒 `source.iterate-scrutinee`（要 Range/List 类型/Iter<T>） | 同上（经类型化 List/Range 即可） |
| default-i64 回绕 | checked i32 `trap:Overflow` | PLAN-997 已认证的 profile 差异；checked-i32 旧 profile 与新通道同语义 |
| `use.rs <crate>` Cargo 依赖 | 声明形 foreign provider（967 受检 shim，冻结域参数） | 1116 交付面；直接 Cargo adapter 等价=后续批 |
| f-string/`print` 脚本面 | console 行为语言车道已接（1116 T-02），值行车道入口仍 `fn main int` | console 作值 oracle 的语料行留作者面（1115 §债） |

## 5. 边界与具名缺口

- **D-1117-1（兄弟仓接线）**：`auto` CLI 生产 owner 在 auto-man 仓；`auto trans
  -t rust` 无 `--merge` 臂存在绕过开关直调 `trans_rust` 且跳过 legacy 计数的孔
  （cmd_trans.rs:308-309）——接收门以 dispatch 回执驳回"标 ACE 实际 legacy"的
  声明（V-03 负控），命令孔修复归 auto-man owner。
- **D-1117-2（多模块语言面包车道）**：包级渲染器/a2x-store packages 车道仍
  RecordText 族；普通语言多模块工程候选=具名缺口（owner：后续包缝批；1115 语料
  31 行多文件包行同归属）。
- **D-1117-3（m2-build 语言发射 session-less）**：A2R 车道语言发射不经 a2x-store
  会话（无 fragment 缓存/计数）；工程级身份缓存在 M2Build 层仍精确命中。store
  族车道语言化随 D-1117-2。
- **D-1117-4（legacy 义务不变）**：旧分母行（1.1/1.2）义务不减；`a2r-std`、
  金样、认证线按原身份保留至 987 退役。
