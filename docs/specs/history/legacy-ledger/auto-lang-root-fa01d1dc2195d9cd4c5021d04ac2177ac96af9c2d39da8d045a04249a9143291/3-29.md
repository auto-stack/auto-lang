可重现性要求 pin 精确版本）；D2 run_a2r 透传（解析失败→TapResult 诊断，不静默）；
D3 fmt_assist **裁定不引入**（unwrap+标注范式更优，三份发射真编译与 VM 逐字节
一致）；D4 五库语料（serde_json from_str 往返/regex is_match/url scheme+host_str+
path/semver major+minor+patch；base64 全红）；D5 网络门控（run_library 对 libs/dep
分类检查 env，未设 skip+提示行）+ CI（parity-ci.yml parity-dep-real-crates job：
nightly+actions/cache 产物缓存+phase p10）；D6 命中率报告三面统计（VM-native/
VM-pack/a2r；同一签名不同面绿红不同，如 host_str Option native 绿 vs pack DIV-DEP-1）。
命名：_real 后缀因 resolve_lib_dir 按叶子名匹配（同名会静默遮蔽 flat 复刻库 p1/p2）。
