PLAN-709 交付（473 系收编线交互收口，auto-lang ui 域）：①拖拽/缩放——WmCommand NativeSlotStartDrag/StartResize/Focus + WmInteraction::NativeDrag/NativeResize 原生臂（几何真值域 native_slot_local_rects；min_size 起点折算字段——min_size_est 物理域在 renderer 起点 DPI 折算+160/120 地板，session 层无 DPI 知识）；__mouse_moved 拦截臂 apply_cursor 消费即尾随 sync_native_geometry 排水（ServiceTick 400ms 不足以跟手的 D3 裁定——每次光标移动即 SetWindowPos，vwin 路径 pending 恒空零新增成本）；拖拽走宿主程序化排水不进 OS move-size 循环，C4 undock 手势天然不误触（E2E 零漂移腿实证）。②统一序域（D2=b 伪 Wid）——槽位伪 Wid（0x8000...|slot 段，与布局伪 Wid 同段）进 focused/z_order/mru：互转助手收口 WmState（native_slot_pseudo_wid/native_slot_id_of_pseudo，FLAG 自 layout.rs 上收单一事实源）；focus_native_slot（伪 Wid 进 focused+带内 OS 置顶随排水拍 restack 旗标）+purge_native_slot_refs（终态全摘除含本地矩形）；焦点回退六处统一 top_member_in_workspace（虚拟窗∪槽位）；Alt+Tab 环/switcher/MRU 并入槽位。③带内 restack——win32::restack_slots（HWND_TOP 锚定+顶向下链插一次成型；473 逐 pending sink_desktop_below 多槽勘误：移除重插语义把先处理槽位压到桌面下方，模拟实证 z=[s2,s1,D] sink(s2)→[s2,D,s1]）；sync_native_geometry 排水尾按 native_slots_in_z_order（当前分区 Docked，bottom→top）全带重申；真洞模式 desktop_above 翻转。④chrome 装配——槽位框从「固定垫全部虚拟窗之后」改统一 z 序循环内伪 Wid 臂插序（假洞虚拟窗层恒在原生窗下不变——仅 chrome 框序变化）；标题条整条拖拽把手（Move 光标）+八向把手（handle on_press 参数化 vwin/槽位共用几何）+焦点/交互边框视觉态。⑤workspace 感知——NativeSlot.workspace dock 时归属当前分区；sync_native_workspace_visibility 失配 tick（IsWindowVisible 探测+SW_HIDE/SW_SHOW，稳态零调用）；带序只含当前分区+chrome 非当前分区缺席；send_to/send focused 槽位臂 move_native_slot_to_workspace（clamp/负一屏守卫/焦点让渡同虚拟窗口径；send_to 解析 N 前缀容收=R1 review 修复，纯数字真实 Wid/伪 Wid 数值回放兼容）；focus_native 任务栏点击「切到窗所在分区」（ActivateApp 同款）。⑥EVENT_SYSTEM_FOREGROUND——docked 命中→wm_focus_native_slot（伪 Wid 焦点+chrome 焦点环+任务栏高亮）；他窗/桌面自身前台不改 WM focused（473「native 焦点域在 OS 层」窄化收口，边界裁定在码注）。⑦投影协议 v1.11——native 条目补 workspace（分区下标串，App 条目同口径；v1.3「不适用省略」退役）+focused 实时位（v1.3「恒空」退役），__wm_wins/__wm_mru/switcher 快照三面同步，指纹 native 段扩 N{slot}:{focused},{workspace}（App 段同型）+mru 段 N{slot};；ShellWin wire 零变化（v1.10 起即全携带，纯构建面增量）。⑧DesktopBus win_rect——win_rect	<wid>	<x>,<y>,<w>,<h>（VM 窗摆位编程化：移动+缩放一体；数字五族全 f32；坏值/缺参/未知 wid/槽位伪 Wid no-op；执行臂 VWinState.rect 直写+160/120 钳制+window_size 同步，无 relayout/不动他窗/不夺焦点/不改 workspace；Free 即落定/铺排布局下次 relayout 重铺=铺排主权）——ToDesk 等远程输入层吞合成输入环境下 MCP 验收通道（autoui_desktop action=bus）即确定性摆窗面，实机三拍像素级吻合留痕。canonical：docs/specs/auto-lang/ui/overview.md（SD-01 709 交互叙述段+SD-03 win_rect
