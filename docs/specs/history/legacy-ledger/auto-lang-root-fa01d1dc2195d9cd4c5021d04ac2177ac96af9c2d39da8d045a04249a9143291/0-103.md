## Original content

补齐 `use back.api` 模块形态（无符号清单）+ 限定名调用 `api.X()` 在 rust/vue 两发射器的支持（VM/桌面动态编译路径既有零改动）。模块形态抽取自 `resolve_back_api` 定位契约的 `#[api]` fn 枚举（ui_gen/api.rs + auto-man/rust_ui.rs 双写，#[api] 门锚 plain fn 不入清单）；限定名与裸名逐字节同发射。R1 复审两缺陷根修：F1 vue SFC 漏 `@/lib/api` import 头（注册器 walker 只认裸名→解包 qualified head，usage-driven 恢复发射）；F2 a2r 单语句 async-Init 漏 `__InitLoaded` 改写（detect_init_api_call 同步解包）。动因 auto-term 017 T-02（merged 进程内唯一可达形态）。
