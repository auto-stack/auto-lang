## Original content

契约=docs/specs/auto-graphics/surface-composition.md：Surface/View/Portal 身份（复用 core::id 代际）、整批校验→整状态提交（失败零副作用）、结构变更与内容适配器本帧输出变化同帧级联消费者、循环/深度预算具名拒绝；GPU 侧每 Surface 一个采样目标（Rgba8UnormSrgb 预乘 alpha、RENDER_ATTACHMENT|COPY_SRC|TEXTURE_BINDING）、2D scissor / 3D 平面（host Surface 相机）、子先于父的 DAG 提交与 DependencyOrder 检查；Iced/2D/3D 三 adapter 记录并校验同一 device ordinal，外设备 DeviceMismatch、无法证明归属 DeviceUnverifiable（fail closed）；目标生命周期计数守恒（创建/替换/丢弃准备/slot 删除）、同尺寸 resize no-op；上传=真实 write_buffer 计量（portal 160B/次、平面 128B/次、内容 adapter 另计），验收要求分管线精确+总量=分项之和+省略计数负控；owned 目标 payload 与进程工作集分开、GPU/驱动驻留具名不可测。窗口/平面组合范围与未支持面见 prototype-profile。

PLAN-857:r1 adds the finite editing depth-assist grid as a default-off auxiliary pass on the same device/queue and presented camera: no depth write, no shadows, no scene nodes or Auto calls; occlusion against real models is proved in composites and a forced-overlay mutation fails the same gate. Auxiliary CPU/GPU allocations are metered separately from immutable mesh uploads with last-owner release on close/resize/cancel; grid off uploads nothing and pixels equal the frozen baseline.
