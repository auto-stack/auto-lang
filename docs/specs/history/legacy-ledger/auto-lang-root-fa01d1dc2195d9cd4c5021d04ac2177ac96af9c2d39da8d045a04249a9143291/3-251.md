## Original content

16KiB 内容寻址快照页+Rc 保活；UTF-8 边界/UTF-16 floor/CRLF 行内策略/分页行索引（跨页续行回溯）。CST=不可变共享内容块+长度目录+根孩子目录（块内边局部下标、块跨树 Rc 共享、封块即 shrink_to_fit）；声明单元相对跨度；无损逐字节重建断言；全路径迭代无爆栈、无固定深度上限。零宽坐标合同：epsilon 放已消费 token 终点（与伪造 start=0 占位可区分）。checkpoint=scanner 实际状态（mid token 含原始起始行；终态按末 token 拼写重放）；增量=嫁接共享采纳（1MiB 中部编辑节点复用≥99.99%/真实读取≤48KiB）+200 轮 fresh 等价；迟到/取消会话域仲裁。
