分层处置：①视图层去卡片化（顶栏 border-b + 列表栏 border-r + 编辑栏，语义 token 全保留）；②过滤层从「视图条件」下沉到 store 命令式索引表（白名单原语：[]int 局部量/嵌套 for/==/!=/状态字段 push；禁用 .field=[] 与局部 []str/[]Note 整赋值）；③编辑模型从模态改为 store 草稿（draft_* + dirty，落盘在切换/筛选/新建前）；④入口 handler 把 API 调用内联在自身 body（生成器只把 body 含 await 的 store 方法标 async，同步方法调 async 兄弟不 await → Vue 端搜索不过滤的根因）；⑤列表栏保留 sidebar 族并补稳定钩子类 note-row 供场景寻址；⑥外观面板内联、退出跨仓 dep。
