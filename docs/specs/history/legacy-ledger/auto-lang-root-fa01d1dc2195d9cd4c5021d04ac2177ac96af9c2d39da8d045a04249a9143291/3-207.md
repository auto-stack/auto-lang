## Original content

PLAN-741 沉淀 current-state 契约：core-i32-draft descriptor 三重身份门（schema/revision/profile）；Atom 文本双槽/命名字段互换、同字段跨区重复拒绝；引用按类别+作用域绑定（模块表 vs 函数体表），category-mismatch 与 dangling-ref 分诊；TypeUse 内建简写与表引用在校验层归一、名义类型不折叠；verify 契约=let 初始化/assign 可变性双查/if 出口交集/循环零次保守/块唯一入口角色/求值位置唯一+表达式无环/入口全路径 return；CheckedModule 仅 verify() 可构造。canonical=docs/specs/auto-hir/project.md；证据=plan-741 text_binding 11/11 + hir_verify 8/8。r2（SD-03）增补：`bindings` 必须为双射（param 全覆盖唯一、arg 越界/重复消费/未被消费拒绝），实参类型按映射逐位核对（params[b.param] ≡ eval_args[b.arg]）不按求值下标对位；新增归属唯一规则——每函数 body 字段必须指向 owner 恰为该函数的 body，共享/同签名共享/冒领 body 在 verify 报 verify.owner-mismatch。r3（SD-05）增补：块包含边仅来自 if 的 then/else 与 loop 的 body（运行时 loop 重入/break/continue 的 LoopId 目标/递归调用不是包含边）；全部块从入口可达且包含图无环——显式栈 DFS 结构检查先于数据流走查，结构失败不构造 CheckedModule（自环报入口角色唯一、断开环报不可达，带定位 span 不 panic）。
