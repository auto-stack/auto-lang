   （pinned 永计为 MAX）、`!pool_is_tombstone(i)`、内容不变,且
   `pool_health().underflow_events == 0`。
3. **语料回归** `test/vm/08_strings/018_loop_concat_churn/`：单发路径循环拼接 +
