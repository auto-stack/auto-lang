## Original content

1. 探针=同 cdylib 导出（非二次编译）：offset_of!/size_of 实测经 auto__shim_layouts
装载期合并，同 rustc 实例保证偏移与 wrapper 对象一致。
2. 指纹传导：nullable 位+字段清单行+enum 变体行+features 行（排序等价）入 C3 payload——
同签名异布局必异指纹；布局行用 emit 期可知输入（字段集），偏移值不进指纹。
3. 快路径 stale：manifest format 拒用+path 源 hash+features 复合键（registry 源版本核对）。
4. nullable 仅 s/p 槽：None→null 指针无歧义；标量槽哨兵歧义显式跳过。
5. unwrap 恒等桥：a2r .unwrap() 透传，VM 侧对 dep 值恒等/null unwrap 报错。
6. EQ TAG_I64 补臂（DIV-DEP-16）：dep 宽整型相等断言此前恒 false。
7. 剔环类型级归因：crate::Type 错误文本→auto__drop_<Type> 剔除（深路径类型误径兜底）。
