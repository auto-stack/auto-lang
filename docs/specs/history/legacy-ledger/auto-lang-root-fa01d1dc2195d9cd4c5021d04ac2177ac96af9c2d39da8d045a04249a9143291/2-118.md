PLAN-733 delivered。VM 渲染目标下模块级 fn 调用（store handler 域与视图 computed 域）契约：返回真实值/参数逐位绑定/失败显式报错不静默返空。执行锚=call_vm_fn 堆引用实参栈编码 encode_list→encode_object 对齐 H2 统一约定（engine 数值臂只认 TAG_OBJECT/裸 i32,TAG_LIST 按空迭代=computed 列表实参恒空根因）+store_scope_module own-module 绑定域（同文件裸名跨模块歧义不再整链接失败）+视图求值器 t() 动态键/Expr::Object 臂。T-01 实证 handler 域本无缺陷（musk"handler 域返空"系输入面误归因）。矩阵锚 plan733_fn_call_semantics_tests;边界见 design/vm-fn-call-semantics.md。
