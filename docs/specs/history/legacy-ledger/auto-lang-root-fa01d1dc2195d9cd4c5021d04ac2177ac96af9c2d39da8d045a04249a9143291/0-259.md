## Original content

Reclassified from compiler misalignment to application-side defect: reading_page.at reassigned a `let` binding, the strict CLI rejected the handler compilation, and the whole Init export was (correctly) dropped as poisoned with zero runtime diagnostics. Delivery = diagnostic visibility surface only: auto-lang finish() logs entry/opcode/code_len/+-4 window and no longer points at non-existent earlier errors; auto-ui record_synth_failure emits [SYNTH-FAIL] on stderr and both VmBridge constructors drain collected failures. Poison detection semantics and byte layout unchanged. Reader side fixed separately (let pr -> var pr, auto-reader 268c7d4, native driver 16/16).
