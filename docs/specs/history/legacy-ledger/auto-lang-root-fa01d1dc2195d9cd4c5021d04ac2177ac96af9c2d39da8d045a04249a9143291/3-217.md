## Original content

非薄 handler 走 a2r 内联转译；后处理链（分割/降级/限定/借用/标准库限定/strip）仅作用于代码区（code_region_mask 转义感知掩码），业务字面量逐字节保留；标准库限定单趟优先级扫描无占位符恢复。模块限定按调用形态+标识符边界（完整 token 身份，custom_a2r_std 类后缀碰撞保持自身身份），绑定按栈式作用域帧遮蔽。借用按实际签名与实参切分（比较 </> 非泛型定界：泛型紧贴标识符、比较带空格；嵌套递归）。返回出口矩阵 InlineRetWrap 五态（Option 变量运行时 match；void return None→状态值、无顶层 return 合成尾；File/Upload 共享入口）；失败 fail closed 不假成功。
