## Original content

Http.get_msg 轮询消费方契约:①共享连接池 Client(禁每请求新建,hyper 池用后即弃=空闲期私有内存棘轮主源);②read_body_capped 按 Content-Length 预留;③载荷单缓冲预编码 {handler}s{json} 入队侧产出、渲染层泵零拷贝直投(原链 292KB 级响应 5-6 份全文拷贝);④DesktopMessage::HttpBackfill 专用通道 seq 门控派发——handler 零状态写不置脏(F1 fire_timer 延伸,普通事件语义不动,逃生门 AUTOUI_MSG_BACKFILL_DIRTY);⑤derive_event_name 的 :: 截断只作用首个  前事件名段(载荷 body 含 std::process 等文本不再截坏 handler 名=musk K10 空渲染族);⑥退出审计四分法:三挂点+main_err(_ai_mode)/mem_guard_f12_escape/native_crash 钩(SetUnhandledExceptionFilter,CONTINUE_SEARCH 保 WER),外部击杀指纹=审计册零行+退出码 1;⑦测量口径:±1MB 堆锯齿在 45s 窗最小二乘虚高一个量级,判 idle 泄漏用绝对增量+≥300s 窗;仪器 finally taskkill 产生的 code=1 是清理假象(判真死亡看 vm_died 与采样时间线)。⑧r2 F-10 exitproc_trace(env P765_EXIT_TRACE=1,IAT 槽替换 ExitProcess/TerminateProcess):依赖直调 ExitProcess 的零痕盲区闭合——原"零行+码1"外部击杀指纹的例外;ExitProcess 臂落调用栈偏移(模块基址相对,release 配 line-tables 可符号化)后确定性自终止(TerminateProcess(自身),规避 LdrShutdownProcess detach 竞态=工作线程退出堆 free 竞态,退出码精确保持);TerminateProcess 臂转调原函数;外部 taskkill 不经本进程 IAT 不在覆盖面;⑨外部击杀假象高发警示:r2 定谳 bigpage 矩阵"瞬态尖峰退出面"=仪器 try/finally 无 catch 的收尾 taskkill 假象(click isError 抛错→finally killTree→"VM EXITED code=1" 先于错误栈打印,node ESM 顺序)——与 soak 假象/musk K14 三例同族,本机"负载相关静默必退"呈报至今零例进程内真实退出;判真死亡须击杀标记与错误分离或采样时间线。
