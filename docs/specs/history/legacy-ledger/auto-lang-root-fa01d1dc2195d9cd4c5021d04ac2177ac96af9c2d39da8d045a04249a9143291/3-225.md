## Original content

PLAN-777 SD-01 落地：scripts/modularity-audit.py 为模块基线与增量检查入口（配置 .autoos/module-boundaries.toml，冻结基线 .autoos/module-boundaries-baseline.json）。持久规则：observe/strict/self-test 三入口；同输入稳定 payload（无时间戳/绝对路径）；规模口径=受管 .rs 物理行（非 SLOC）；声明边主源=成员 manifest path 依赖（normal/build/dev/optional/target，workspace 继承按根解析），cargo metadata --locked 仅对照（缺锁记 gap）；域表按包名（含已知外置实现包 auto-ui/auto-man），未登记保持 unclassified；文本扫描为启发式候选（盲区显式）；strict 判当前工作树边集、规则须有域方向（scope-only 惰性）、存量豁免绑定完整声明身份+逐边 owner/exit_phase、撤销/漂移/过期/宽豁免不得静默通过；输出守卫保护全部受管输入+实读 manifest+锁（含大小写/硬链接身份别名）。基线不表示 AutoUI/AutoMan 已拆仓。
