## Original content

为 AutoVM 动态加载**真三方 crates.io 库**建 R 层 parity 对拍（PLAN-592 后续线）：
serde_json/regex/base64/url/semver 五库经 `dep crate(version) + use.rs` 动态加载，
parity 工具三轨（VM/a2r/oracle）TAP 对拍。1) P0：auto-parity deps.rs 本地解析器
（crates.io 版本 pin 专用）+ run_a2r Cargo.toml 渲染透传（转译器零改动）；
2) libs/dep/*_real 新分类（_real 后缀防 flat 复刻库叶子名遮蔽）；3) AUTO_LANG_PARITY_NET
网络门控 + phase p10（parity-ci 独立 job）；4) 红面 DIV-DEP-8..14 显式登记；
5) 命中率报告（25 面/绿 8/32%）回填 591 待澄清 #4。执行期三裁定：fmt_assist 不引入
（unwrap+标注范式双侧实证）；CI 宿主 parity-ci.yml；base64 全红样本不进 p10。
