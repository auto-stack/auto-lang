PLAN-793 交付：AutoError 聚合与语法/类型/名称/运行时/comptime/警告各族诊断+WithSource 包装+attach_source/format_error/find_best_match 单一实现自 auto-lang/src/error.rs 逐字迁入 crates/auto-diagnostics（唯三补丁：Name→AutoStr×2+头注；TypeError::CannotModifyViewParam 载荷=auto_val::AutoStr 同一类型，error→AST 边切断）。normal 闭包仅 auto-lex+auto-val+miette/thiserror（module-boundaries 域 lang-core）；auto-lang error.rs=20 名冻结公开面薄门面（auto_lang::error::* 路径/身份零变化），owner 侧 From（route/discovery、infer/unification）合法留存；多错误收集上限留 auto-lang lib.rs。同一性合同 auto_lang::error::X ≡ auto_diagnostics::error::X，消费者不得降级 String。外部消费门 diagnostics-consumer+verify-deps；互操作门 interop-consumer（真实 parse/type/name/route 阶段保持）。
