## Original content

PLAN-802 SD-02：CodeEditorRegistryProvider（无状态）委托 ui::code_editor 既有注册表（单一真源，不复制第二 registry）；滚动三项委托 editor_scroll_handle+scroll controller 注册表（非 794 通用参数协议）；文件 IO/OS 剪贴板留 UI 实现侧。code-editor 单门控 + cut/copy/paste 实现级 ui-clipboard 门控（缺=返 None=组合特征 raise 臂）。宿主接线四点 if-absent（install_ui_host_capabilities/run_file_dynamic_ui_inner/VmBridge 两构造）。R1 修复轮补 render_dynamic_view code_editor 臂 bind_controller（与 desktop 泛型臂同款）——修复 PLAN-629 起 VM 轨漏绑致 scroll_to 写端点 intent 被 drain 静默丢弃的预存缺口。未迁族清单收窄（editor 22 项出列，余 diff/dnd/term/media/dialog/ffi）。
