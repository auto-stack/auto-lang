# Legacy Spec: Poisoned-export drop is self-describing; the drop decision is correct

## Original content

poisoned_fn_exports (non-special export name whose code[addr] != FN_PROLOG) keeps dropping half-built exports; the drop point now prints entry address, the byte found there, code_len and a +-4 byte window, and never assumes an earlier error line exists. Root cause of the reader case was an app-side illegal `let` reassignment that made the whole handler fail to compile, not an FN_PROLOG insertion/reloc misalignment. Companion consumer surface: [SYNTH-FAIL] on stderr from auto-ui-runtime handler synthesis (both VmBridge construction paths).
