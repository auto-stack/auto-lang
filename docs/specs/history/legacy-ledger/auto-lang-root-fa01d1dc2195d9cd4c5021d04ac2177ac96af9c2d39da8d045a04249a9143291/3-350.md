## Original content

PLAN-862:r3 adds the entry-unit source profile (auto.source.entry-unit.draft rev 1; HIR auto.hir.entry-unit.draft/1/entry-unit-draft): three mutually exclusive entry forms (fn main() int, fn main() void, single-file script whose i32 tail is the result), plus uniqueness / zero-parameter / full-return / tail rules with named diagnostics (source.entry-missing/duplicate/ambiguous/params/top-return/order/result/tail/tail-type, source.unit-return-value). Unit is a RESULT-only type: writing the void type word in a parameter or local names source.unit-placement (reachable since the T-07 repair), while field/place placements are gated at HIR (verify.unit-placement) and MIR (mir.unit-placement). The profile is AV-only: no native lowering, other consumers reject explicitly, and the old four profiles keep byte and semantic parity (void/expression statements stay source.unsupported).
