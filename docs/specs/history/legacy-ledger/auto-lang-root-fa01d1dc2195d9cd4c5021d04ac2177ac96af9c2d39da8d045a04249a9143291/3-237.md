## Original content

PLAN-785 SD-01：auto.clipboard.text/set_text 经 vm::host_capabilities::ClipboardTextProvider 供值，core 两 shim 零 ui::clipboard 直引。接口值域 owned String 出/&str 入（零 VM 索引泄漏）；VM 编码保持 add_string/rc_push_str_idx 与 pop_string_arg/encode_bool 既有路径。缺席=原 feature-disabled VMError（文本逐字）；在位不可用=空串/false。三层装配优先（显式 set 恒胜/if-absent 同锁补缺/实例独立）；AutoVM 构造快照、NI Clone 与 VM merge 保留 provider；注入不 bump binding_revision/proof。Send+Sync 仅约束 provider。测试纪律沉淀：缺席断言锚=构造式（cfg(test) new_without_host_snapshot）+外部独立进程 fixture 承担全局缺席时序合同；清/写全局槽的测试共锁，普通程序测试零配合（其唯一槽写 if-absent 无害）——生产写域方案因 run 族 execute/install 跑在 spawn VM 线程上构成持锁者 join 环被否决（watchdog 栈实录）。
