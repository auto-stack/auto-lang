## Original content

PLAN-730 交付落账（canonical 唯源=docs/specs/stdlib/design/http-server-uploads.md）。公共面：UploadRequest（宿主注入、一次性、不能从请求字段伪造 root/staging/target）/UploadSession（接收快照，失败会话可 inspect/reject 不能 commit 成功）/UploadReceipt（真实 status+有界 JSON，成功 commit=201，size 十进制串）；upload_receive(req,root,staging,options)→metadata→commit(relative_target)/reject(status=0 采纳建议状态)/error(400..599) 五原语（receive/commit/reject=await 点，同步上下文指名诊断）。接收合同：路由/中间件/header 校验先于任何 body 解析或落盘（100-continue 实测）；VM 桥按方法+参数类型双条件延迟 body、生成腿 Request 提取器置最后不预读；mode 显式 multipart|raw（multipart=RFC7578 单文件子集：恰 1 file 字段+有序有界文本，缺 file/第二 file/未知字段/嵌套/CTE/非utf-8 charset 明确错误，boundary≤70B，假前缀跨块回吐；raw 整 body，Content-Encoding 非 identity 415）；预算单文件 64MiB/wire 65MiB/文本 16×16KiB·64KiB/part 32/块 64KiB·待写 2/fs_ops 4（env AUTO_HTTP_UPLOAD_* 或 options 只降不升）；期限：准入（queue+active）受队列期限 30s（R1 修复——此前 active 臂误用 total 致满额吊 30s）、idle 60s、total 10min（scope deadline watch 切换）、staged lease 30s。staging：受信同卷私有目录（嵌套/缺失/跨卷读取前拒）create_new 独占，EOF+flush+sync 后 staged；提交：词法校验（复用 server_file validate_relative_path）+父目录 no-follow walk（仅已存在目录）+hard_link 原子 create-only（存在 409 原文件不变/EXDEV 配置诊断）+unlink staging；取消仲裁 gate=hard_link（前取消胜出不发布、后迟到取消等实际结果成功保留）；writer 通道关闭自清、清理失败记 request id 不宣称零残留、lease 过期墓碑 410。legacy multipart 兼容修复：路由先行（404 零解析零写盘）、解析纯内存/落盘移 middleware 后宿主 spawn_blocking、写失败真实 500 无假路径、provisional 绑定失败/handler Err/取消清理成功保留；10MiB 上限与 {fields,files} 形状不变。支持矩阵：VM+生成 Rust 两腿同源（a2r-std server_upload 类型/facade→auto_lang http_upload_service executor hook）；TS FormData 直传；Tauri/back-proxy 明确拒绝；727 客户端↔730↔729 下载同字节闭环。
