## Original content

PLAN-862:r3 delivers av.entry-unit/1, the seventh AV execution profile (MIR auto.mir.av-entry-unit/1; ABC auto.abc.av-entry-unit/1 = new AVAU family, wire v1, profile id 7; producer plan862/av-entry-unit). Value::Unit is a real zero-width payload that is never equal to I32(0); EntryKind{Int,Unit} is carried in the wire header and checked bidirectionally against the entry signature (mir.entry-kind, kind-less rejected); Unit slots are restricted to the unit entry's result and its single return operand (mir.unit-placement); AVAB and AVAD v1-v5 are mutually unreadable with the new family and a legacy owner schema is rejected (mir.schema-profile). Recovery re-decodes and re-verifies every envelope with profile+kind identity, cache namespaces are profile-scoped (AVAB/AVAD rows are deterministic misses), AV still executes on a hit, and a body edit rebuilds only the edited unit. Execution budgets are unchanged and the profile adds no allocation channel.
