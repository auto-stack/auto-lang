## Original content

PLAN-724 交付落账（a2r-std 域现行态投影；canonical 唯源=docs/specs/a2r-std/design/http-client-runtime.md，delivery 8a7fa3cee）。契约：两条 Rust facade（独立 a2r_std::http 与 auto_lang::a2r_std::http 生成服务限定名面）全部网络执行单源到共享内核 http::client——reqwest async + 固定 multi-thread runtime（OnceLock 单例，AUTO_A2R_HTTP_WORKERS 默认 2）+ 复用连接 Client；async 面通知等待（丢 future 即取消），同步桥接为响亮边界（async 上下文 panic 不静默阻塞）；限额 active 8/queue 64/体 10MiB/总期限 30s、流 active 16/queue 32/队列 16×256KiB/raw 16KiB/建立 10s/idle 60s；流单次终结（Data/Eof/Failed），close/Drop=finalize+abort 生产者，EOF 先排空；headers JSON/行双适配器终结性报错；707 SSE decoder 原样提取 a2r_std::sse 单源共享（plan707_decode 零漂移守卫）；文件 helper 仍 ureq、sse_open int id 族不在 a2r 支持集。证据：724-client-decision/parity/resource-lifecycle 报告 + http_e2e_plan724 三腿 + a2r-std 43 测试。
