PLAN-667 底线钉定的三值支持边界（已验证支持/明确拒绝或受检运行期错误/不属于本次保证）：VM by-ref 捕获经 (task_id, frame_uid) 帧身份活跃表在槽位读写前校验——创建者存活（含同步谓词/嵌套继承祖父帧锚/生成器挂起）为支持面，已返回帧/同 bp 复用/跨任务/挂起 async 体后=RuntimeError 拒绝；RC=影子/tagged 计份+rc_stats 纯读（显式 reap_all 收尾）+rc_retain_id 存在性门+rc_push_slot 份额出处门（无影子裸 i32≥4M 真整数零计数，撞活 id 不冒领）；a2r=闭包捕获升级（源序遮蔽自由变量收集）+fold_to_root 名称合并保守身份（生成侧恒 depth0 查询）+未覆盖 AST fail-closed+`.mut` 于逃逸绑定与 Send 边界（`.go` a2r 解析层即拒/ArcMutex emit 层拒绝）明确诊断。宽限窗降格为回收策略；类型化 var 槽位影子缺失=P667-D1 债（泄漏方向）；下一版语法/编码退役均未实现。证据 reports/667-memory-safety-evidence.md
