## Original content

PLAN-705 交付（Design 33 阶段 C1）：VM #[api] handler 普通异步等待即 park/resume——owner loop COMPLETION_NOTIFY enable→check→await 零轮询零丢唤醒，等待上游期间 health 照常服务（gate E2E）；入口矩阵 named/middleware 链/__axum: closure（call_closure_segment）/RequestBuilder .send（段模式退役 30s drain，rewind ip−6+Yield，重入凭据=waiting 标志与 CALL_NAT 协议同构）；~T 返回元数据门（API_ASYNC_RETURNS，__axum: 经 func_addr→exports 反查）+ future bits + 注册表存在性三重闸（普通 int 240 反例锚定），External 挂起/内部体就地驱动/挂外层 AsyncReturnBody 三形态。请求作用域：AUTO_HTTP_MAX_INFLIGHT 升级为 queued+running+parked 生命期总上限（兼容性明示），桥入队前 try_acquire 满载 503 零排队；取消三类确证判据=回复 deadline/shutdown/连接任务终结（net watcher），半关闭/EOF 不判取消（hyper half_close(true)）；失效排队出队跳过业务函数，parked 失效废弃回收 live-op（presence 守卫拒迟到复活），排水窗 AUTO_HTTP_SHUTDOWN_DRAIN_MS 内自然完成照常回复。跨 await 非原子事务（副作用不回滚）。顺手闭合：intercept_error 跨帧展开（深帧 try 经 park/resume 后 catch 失效——引擎既有缺口，plan705_engine_deep_frame_try_recovery 回归在册）+ 706 lucide_component_name 纯 VM 形态编译断（cfg 门）。canonical：docs/specs/stdlib/design/http-handler-async-lifecycle.md（SD-01 新建）；SD-02 修订 async-http-result-lifecycle（单次终结/取消不复活/固定 async executor 五限额）；SD-03 修订 http-server §8.1；SD-04 修订 networking-stdlib 阶段 C1 标注。回归：plan705 探针 19 项 + 广谱 522 + tf 全量 5819/5832（10 项 base 预存红逐项复证 + 3 项 oracle 争用偶发隔离绿）。
