## Original content

SD-01：方言端口合同唯一实现——轻 CompilerSession/Scenario/DialectPriority + ExternalDialect trait + 对象安全 ParseContext 端口 + 快照凭据 ParseCheckpoint；依赖闭包仅 auto-ast/auto-lex/auto-diagnostics（lang-core 域，777 规则），轻层门面 re-export ast/token/error 与旧 auto_lang 模块名对齐；外部文法实现闭包零语言实现（dialect-api-consumer+verify-deps 钉住）。快照寿命按签发作用域失效（F-801-R1-01：槽位记 scope+port_release_scope 归属清理，tombstone 复用不可绕过；跨上下文/过期受控拒绝且游标不动；move-only 单用；无 unsafe/无源码静态生命要求/无全局池）。剩余边如实：内建 UiDialect escape hatch 完整文法在 Parser、生产入口注册不自动注入、widget 体 model 直连。
PLAN-842:r2 UI 统一中立领域端口，非 UI 外部方言和优先级保持。
