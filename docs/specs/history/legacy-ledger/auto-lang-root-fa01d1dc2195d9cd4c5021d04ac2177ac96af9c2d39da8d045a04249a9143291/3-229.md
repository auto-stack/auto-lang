## Original content

PLAN-780 SD-01 落地：crates/auto-project-model 仅依赖 auto-atom/auto-val（normal 闭包无 compiler/VM/man/UI，外部 consumer 独立 manifest 门）。公开 parse_document/parse_file 只读入口；ProjectDescriptor 冻结字段归一化对齐 Pac 语义（identity/render 三形态+legacy/scene/members/defines/dep 裸名-引号-参数/展示运行字段/toggle/external_backend+source 行号）。纪律：未知属性/节点入 raw_props/raw_nodes（dep 体 children/重复/行号保留，重复 path last-wins）；变量/调用/插值/赋值/f-string/root wrapper/类型形态 unsupported 分类或 stage 错误，非静态不计等价、无静默回退。注释/分隔语义：块注释内换行仅位置不分隔；数组/对象逗号规则不对称（数组值后逗号换行注释混排、对象逗号仅同行）；顶层 # 注释合法而容器值位 # 双臂拒绝；id6 逗号混排（["a",/*c*/,"b"]）为保留限制（AtomParser 值层拒绝，不假 static）。错误带 path/stage/位置，Io 失败必红 corpus 门。对拍探针 auto-man project_model_adapter（170 受管文件=157 static 相等+9 dynamic+2 template+2 both_rejected，豁免=精确全路径清单+stage 诊断）。生产读取零切换；后续接线按 T04 owner map 另立计划。
