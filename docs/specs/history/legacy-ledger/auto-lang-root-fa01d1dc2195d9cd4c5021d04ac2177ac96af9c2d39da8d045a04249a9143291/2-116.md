## Original content

Design 33 阶段 B 全 delivered。①传输（SD-01→http-server.md §7.3/§8.1）：VM #[api] HTTP/1.1 迁 Axum/Hyper——专属 auto-http-net 线程 + hyper-util auto Builder（http1_only+TokioTimer+64KiB 头缓冲+10s 慢头读超时）+GracefulShutdown；手写 handle_connection_async/write_api_reply 退出调用图；chunked 请求体与 keep-alive 由 Hyper 承担（chunked 旧为直接拒绝=设计内放松）；资源预算冻结面：头 64KiB+≤100（超限原生 431）、慢头 10s 关闭、body 10MiB（413）+收满总期限 10s（408）、在途队列 AUTO_HTTP_MAX_INFLIGHT 默认 64（满载立即 503+Retry-After）、回复等待 AUTO_HTTP_REQUEST_TIMEOUT_MS 默认 30s（503）。②owned 桥（AC-02）：ApiRequest/ApiReply 全 owned Send（method/path/headers/body/peer ↔ status/headers/body 或 Sse 帧通道），有界 mpsc→VM owner 循环 dispatch_api_request（CORS/限流/请求 id/multipart/路由/中间件/绑定/handler/Response/POST 广播语义逐行镜像旧内联路径），零 Rc<AutoVM> 跨线程、零 usize 洗指针、零 spawn_blocking。③SSE/关闭：696 producer+capacity-1 帧通道原样；FrameStream 以 Receiver::poll_recv 接 waker（try_recv+Pending 无 waker 永久饿死=spike 实证坑）+关闭旗标收流；断连/关闭在 owner 线程回收 iterator/task/698 订阅；优雅关闭=serve_async 缺省 ctrl_c(+unix SIGTERM) 置 watch 旗标→停 accept→drain 10s→强制关→端口复绑（serve_with 注入信号同通道，E2E 全链绿）。④Spec 三面：SD-02 backend-assembly http 行+拓扑表+696/699 锁定行为节（VM 与生成 Axum 均依赖 Axum 但为两套独立服务实现）；SD-03 networking-stdlib 传输现实注记（Auto task 通用异步 I/O 仍属 Design 33 阶段 C 未落地，handler 无抢占）；顺带 reconcile 698 前的 bus.subscribe compile seam 过时行。axum 转 auto-lang 无条件依赖（ui-interpreter 摘 dep:axum 保 dep:ureq）+hyper/hyper-util 直依赖。
