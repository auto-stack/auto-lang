ui VM 轨 menubar/MCP 契约（PLAN-664 U-1，消费方=auto-edit 041 矩阵与 jade-garden desktop）：①Popover 子树全量进快照——view_to_vtree_with_paths 对 widget 锚形态收录 [anchor, content] 双子（Plan 422 子序约定）；menubar 降级（PLAN-630 声明式组件族/Plan 418 actions 合成同机制）把展开项建在 content 面板内。②开合状态是渲染器本地态（action_config::MENUBAR_OPEN 进程级 Mutex），toggle/close 走 __menubar_toggle(id)/__menubar_close 内部消息（␟s␟<id> 载荷编码）。③自动关闭判据=用户交互近似：menubar_open() 时非 __ 前缀消息关菜单，但 TimeSource 泵事件除外（DynamicComponent::is_timesource_event 对 timesources 声明全集事件名匹配——DSL Tick/timer{} 处理器名天然无 __ 前缀，是框架周期消息非用户交互；041 状态栏时钟每秒 Tick 曾把刚开的菜单在下一次快照前关掉=041 矩阵六失败根因，39/5↔39/6 波动=竞态）。④MCP press 通道带参可达（extract_dyn_msg encode_payload 编 args 进事件串）。同批：use 导入 P-15/P-16 静默死面编译期告警化（[AUTO-USE-DIAG] 前缀+take_use_diags 汇聚；F-1 卫=auto.* 内建/.web ext 表单/use.py 三族非文件形态不告警）；jade 值域词位勘定=全部已落地可组合（Array.isArray 全域/Json.type_of(JSON.stringify(v)) 值域 typeof 分派/storage str 域读回链，语料 test/vm/99_plan664 锚）。
