## Original content

PLAN-734 交付落账（canonical 唯源=docs/specs/stdlib/design/api-transport-contract.md）。api/contract.rs 单源：ResponseKind（File/Upload/Stream/ExplicitResponse/Void/Json）与 ParamKind 按裸名/泛型解包精确匹配（MyFileResponse/List<FileResponse> 假同名不命中）；is_upload_param 双族（API 元数据裸名+VM 签名 s-expr type-decl 名字段等值）；META_PARAM_NAMES/whole-body 单参容忍为显式 ParamSource。53+ contains 生产位点退役（7 文件 grep 全零，R1 修复 8 残留）。参数绑定：body 值按声明类型校验（str-for-int 400、float 非有限 400、optional null）；int=i64 全域（bind encode_i64_with_heap+定点范围校验、json_to_vm_value 全域、nv_to_json i64/u64/bigint 臂、String 编组 i64/u64/bigint 臂+vm_value_to_json Value::I64 臂——缺失即 664 值域红 R2 实证）。返回：Upload/File declared 门+iterator/response-handle 注册表命中制（Plan 326 int 声明 wire 契约兼容裁定，二分证据）；{"error": 前缀猜测退役（error 字段=200 数据）；序列化失败 500；merged noop→可定位 VMError。back-proxy：primary 半段分类+参数面补充+headers meta 源。债 P734-D4（stdlib i32-lane json.encode 返回通路/str+int 拼接）。
