PLAN-715 交付落账（website 域 SD-01/03/05 现行态投影；canonical 唯源=docs/specs/website/design/ui-presentation.md（新建，SD-02/04/06）+docs/specs/website/project.md 增补，landing ddb47205e）。契约：theme/data/navigation.ts 为中英导航单源，共享 SPA（/ui/gallery|blocks|charts|a2ui|demos）双语同 URL 标注"共享"禁造镜像路由，规范入口 index.html（sirv 目录 URL extensions 解析使 /ui/a2ui/ 优先命中专题页为既定行为）；aria-current/aria-expanded/Esc 焦点往返/44px 触控；主题态统一 useData().isDark。站内搜索=VitePress local provider，SiteSearch 合成 Ctrl/Cmd+K 热键接线（官方 poll 同法，弹窗 Teleport body 不受 VPNav 隐藏影响），CodeMirror 捕获守卫防抢编辑器输入，升级需回归 1.6.x 行为。HomeDemo 三视图：初始预置标源（纯 pre 不发请求），点击运行才发同源 /api/run，10s 超时可取消离页清理，stdout/stderr 分列，预置永不显示为实时成功，Rust 视图仅限有真实 a2r 金样的示例。图片骨架：EvidenceImage（Enter/Esc/焦点往返/loading/尺寸占位/framed）+ScreenshotGallery（tab 键盘/不自动轮播）+AppLandingLayout（hero 骨架；md 组件调用压单块禁空行、顶层内容去 4+ 空格缩进）+ReleaseLanding 数据驱动（首图 eager top<1.5 视口/理念 details 展开/统计后移/无 TODO 占位）。历史收据=plan §9（archive/715）。
