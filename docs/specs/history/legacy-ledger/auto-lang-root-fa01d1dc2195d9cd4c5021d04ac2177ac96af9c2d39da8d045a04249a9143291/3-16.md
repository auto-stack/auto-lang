## Original content

PLAN-778 pilot：Dialect::try_parse_stmt/try_parse_token_stmt 收最小 ParserBridge（游标/checkpoint/核心 expr·type/context/syntax_error 工厂；不暴露 Parser/lexer/符号表，无通用 warning 出口）。register_dialect/with_dialect 显式注册，Override 前插/Append 后接，with_session 只重建内建段，派发时 matches 场景门控；Arc 共享句柄——委托递归期间活跃方言留表可见。恢复不变量（核心保证）：Ok(None) 回滚游标+五旗标（in_on/in_fn/in_dot_rhs/with_header/body_depth）；Err 不丢注册、边界恢复五旗标、游标留失败位；errors/warnings 单调追加，无全副作用事务承诺。外部已验证 model 冻结子集 model { [var] name [type] [= expr] }（裸字段=行界/块界终止，Unknown/Nil；内建路径不变仍要求类型或初值）；注解 None 回退内建；widget 体 model 直连内建不经方言派发；生产入口/导入不自动继承注册。旧 mem::take 移表坑点已原位替换废弃。
