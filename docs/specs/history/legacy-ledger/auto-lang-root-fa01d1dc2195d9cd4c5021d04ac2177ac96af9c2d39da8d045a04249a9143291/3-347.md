## Original content

boot 期只读自检输出 [desktop-health] 一行 key=value + 可执行 hint：apps_dir(_src)/registry/desktop_visible/skip=no_pac_at:N/declared_exe_missing/apps_empty/shell_pack(_src)/storage/orphan_icons/auto_cli。skip 与 orphan 的 known 集直读 apps.manifest（active 全量；不用会被 pac.at 过滤的 manifest_repo_roots）；orphan=∉(entries∪manifest)，apps_empty>0 时不给清理建议。desktop_exe 声明只在产物在场时命中原生；manifest launch=native 严格失败、vm 恒解释态、缺省降级解释态+stderr 一行。auto CLI 寻址=AUTO_BIN/AUTO_CLI→自身及上三级→PATH（含 auto.cmd）。
