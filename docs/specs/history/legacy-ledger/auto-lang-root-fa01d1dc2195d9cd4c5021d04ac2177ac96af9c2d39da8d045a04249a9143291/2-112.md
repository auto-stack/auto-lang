## Original content

a2r 生成 exe 渲染底座参数化：`--render-mode independent|rq|desktop` + `-q/--rq` 糖 + `--desktop-endpoint <pipe>`（desktop 必需）+ `--window/--title`；优先级链 CLI > AUTO_VM_RENDER env > pac desktop_render > independent（F-3 关闭口径：缺省恒 independent，remote 族显式选用；queue/auto=帧覆盖声明跳过降级）。rq 臂=exe 侧 ensure_rqhost_ready 孵化+采纳；desktop 臂=不孵化直连（端点缺席报错提示先启动桌面）；显式 CLI independent 覆盖孵化注入（CLI 顶优先）。单源 render_cli.rs（parse/resolve/sidecar pac）。同批双潜伏缺口根修：PLAN-683 ClientOpts.remote 生成器同步（E0063）+PLAN-691 gpui 残留 emission 摘除。实机三形态四截图 reports/p693-tri-mode/。
