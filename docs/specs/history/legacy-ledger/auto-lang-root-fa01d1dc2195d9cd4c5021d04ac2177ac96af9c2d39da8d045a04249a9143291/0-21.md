## Original content

清偿两个存量语义缺陷（531 式债批，python-parity-roadmap §7.4 队列 ⑦）：
1) **P539-D3** py_call 糖族恒括号纪律七臂（py_call/py_call_may/py_getattr/
py_matmul/py_getitem/py_setitem/py_call0——审计较原单点扩容；复合接收者原裸
拼接致 `.sum()` 绑到末操作数）；2) **DIV-PY-CLOSURE-1 双面清偿**——a2py 面：
语句体闭包原发射 `lambda x: {...}` set/dict 字面量（单表达式块静默错类型、
语句块语法非法），改为单表达式块 lambda 化 + 含绑定/多语句块显式诊断；
VM 面（实勘扩面）：collect_free_vars 不识别块内 let 绑定（STORE 本地槽/
LOAD 走捕获环境错位）+ 闭包局部帧无预留（bp 相对寻址落未分配栈）双根因修复。
3) de-workaround 判定：py 套件零活跃规避点（验证式清零）。
