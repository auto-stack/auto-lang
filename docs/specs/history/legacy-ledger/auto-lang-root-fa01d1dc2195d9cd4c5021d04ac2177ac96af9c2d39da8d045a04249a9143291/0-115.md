## Original content

VM split 模式（AUTO_VM_MERGE=0）的 #[api] 调用改写此前仅匹配裸名（Expr::Ident）——限定名调用（api.get_lines()，use back.api 惯例=545 规范形态）绕过改写、静默回落 back 链扁平体进程内执行，宿主进程引擎缺席时全空返回（auto-term dev 跑法空屏/T-10 委托断供定因）。现两合成入口（synthesize_widget_module/synthesize_from_decl）api_funcs 注册限定名键（扁平化全名+别名末段.fn 双形态），codegen 门卫放行 Dot(Ident,fn)；db.* 等非 api 限定名不命中表不受影响，merged 路径零改动（plan340 回归双断言锁定）。AUTO_LANG_HTTP_TRACE=1 仪器常驻 simple_http_json（api 改写家族 HTTP 汇聚点：方法/URL/状态/响应摘要）。次生登记 P648-D1：事件 handler 在 HTTP yield 期间被再入会破坏任务状态（单槽 waiting_http_request_id+同任务帧覆写→循环上界失效无界自旋，纯窗口事件即可触发），交互稳定性独立立项。
