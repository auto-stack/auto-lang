## Original content

UI 专属 AST/词法分类/解析产物归 auto-ui 的 ui-domain-model 拥有：UiAst/UiStmt 与版本化 UiCode codec、递归 visitor、快照/Weak 最后 owner 语义；Core AST/词法/Parser API 只保通用模型与中立领域端口（DomainDialect/parse_domain、external-ident checker），View/On 共享 Token 与 Core 同名语义不变，旧 UI 兼容臂/文法 inventory 装配退出。UI 经 lower_ui 校验/lowering 后进入类型、VM、四生成器与 SDK；导入失败在 VM 构造前拒绝，缓存身份按新模型版本化。运行期 Init demand 快照递归持有 typed VmRef、重播逐层物化 ListData/ObjectData，parked 段 resume 失败当场回写 Failed 终态（M841-GATE-05）。canonical: docs/specs/ui-domain-model/project.md 及 SD-01..05 各目标。
PLAN-842:r2 Aura 旧入口及旧方言适配已退役，DynamicComponent 导入语义保留。
