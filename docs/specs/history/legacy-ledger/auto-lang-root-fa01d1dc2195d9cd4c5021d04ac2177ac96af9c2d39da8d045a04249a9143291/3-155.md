## Original content

PLAN-724 交付落账（stdlib 域现行态投影；canonical 唯源=docs/specs/stdlib/design/http-stream-lifecycle.md，delivery 8a7fa3cee）。支持矩阵增"Rust 客户端已迁移"：a2r 两 facade 外部流消费收敛到共享 async 内核（有界队列/背压/期限/真取消/SSE 共享解码），707 状态机/预算/单次终结语义以 Rust 形态同构落地于 http-client-runtime；协议差异明示——VM 轨=park/resume 凭据+引擎泵恢复，Rust 轨=async await/通知等待，两者不共享资源表与许可；非目标项移除 a2r-std 迁移（已完成），保留 auto-man 生成服务任意外部流 handler（另案）。

PLAN-840 r8: SSE pull and nested generator driving clone task Arcs and release DashMap shard guards before executing instructions that can insert tasks. Forced shard collisions reproduce old deadlocks; real event values, park/spawn bound, nested value/EOF/task cleanup and adjacent cancel/backpressure controls pass. No timeout relaxation or new polling.
