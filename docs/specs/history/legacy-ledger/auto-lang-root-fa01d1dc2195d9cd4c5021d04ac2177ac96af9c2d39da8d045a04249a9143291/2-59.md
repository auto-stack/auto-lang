## Original content

三源语义（三轨同律，缺一即红——parity 锚 extra_roots_three_track_parity）：
①框架 demo=默认注册表（examples/ui，语义未动）；②local=../auto-os/apps
容器展开（每含 pac.at 直接子目录一 root，id=子目录名）；③repo=apps.manifest
条目→extra root 原生挂载（id=manifest id，repo 相对 manifest 根解析，pac.at
门控）。优先序：storage/env 显式 > 探测（单根+容器）> manifest（同 id 先入
表胜）。manifest 解析序：AUTO_OS_ROOT（设置即权威，指空=显式关断）→兄弟
→主检出兜底。manifest schema 定稿（Design 01 §1-C）：{id,name?,repo?,
kind:repo|local（缺省 repo）,ports?,status?（缺省 active）,added?}——宽容
读取，未知字段忽略，坏条目跳过+警告不阻断启动。iced 轨经
DesktopOptions.extra_app_roots 显式覆盖（apps_dir 先例）；vue 轨经
AUTO_DESKTOP_APPS_EXTRA 全额覆盖（manifest 不并入 env 覆盖路径）。
