## Original content

编辑器滚动条改用 AutoUI 公共 scrollable（官方样式/交互），自绘滚动条与内部滚轮路径退役（headless 保留）。集成契约三机制：content_height 实时 fold 投影上报（高度变化→request_redraw→view 重建重排）；draw 每帧 viewport 偏移 sync_external_scroll（粗定位 line+offset 余量+shape_until_scroll 归一,虚拟化只 shape 可见行）；键盘/IME 光标跟随经 core 请求标记+dispatch_app 尾部排水成 operation::scroll_to（M 泛型路径不可用消息通道的既定绕法）。caret_offset_y 直接计算不依赖渲染记录。教训：iced Shell 无布局失效 API,消息/重绘即失效通道。 archived。
