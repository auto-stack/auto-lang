## Original content

PLAN-873:r3 delivers the build-cost baseline: isolated-target protocol (wrapper-unset, >=3 samples median+range, rustc-only pollution guard, per-site sha reset) and measured L1 cold/hot check (lang 80.0/0.9s, core 55.5/0.5s, ui 84.2/0.6s, man 105.9/0.7s), L2 three-control incremental at 7 real function-body sites (lang-core any-family single-line edit = 4 crates across 2 repos, 6.9s check vs 5.9s mtime-only floor vs 0.7s no-change; ui-compiler 4.6s/4 crates; ui-runtime 4.6s/3 crates; man 1.2s/1 crate), L2e edit->test-binary (27.4s lang / 22.9s ui-runtime / 4.9s man warm vs 196-277s cold), L3 list/enumeration split, L4 receipt-only full-tier walls. Decision model: split benefit upper bounds ~0 cold / <2s check / est.10-15s test-binary vs permanent structural costs; verdict = do NOT split members now; alternatives A1 ui-iced out of default features (own sign-off) / A2 sccache steady / A3 test tiers / A4 mtime-cascade observation; trigger conditions T-A..T-D to reopen; if-split draft = trans member first (acceptance metrics + risk list). Observations O1-O5 incl. cross-repo mtime cascade and man 9-member counterexample. Runner scripts/measure-l2-873.sh + measure-build-cost-873.sh.
