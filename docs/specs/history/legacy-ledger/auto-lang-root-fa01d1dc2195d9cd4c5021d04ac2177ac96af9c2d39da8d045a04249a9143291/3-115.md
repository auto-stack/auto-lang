## Original content

ui/iced 渲染前 pre-pass 双语义（PLAN-663）：①视口边界（iframe 语义）——SizeValue::Screen 与 Full 严格区分（h-screen/svh/lvh/dvh/w-screen 族 vs 父容器百分比）；rewrite_viewport_units 在定高(px)嵌入边界子树内把 Screen 族重写为 Pixels(边界)（min-h-screen 的 f32::MAX 标记→MinHeight(边界)），窗口根 Screen→Fill 满窗不变；边界判定仅认 arbitrary px（spacing 定高不建边界 P663-D2），宽/高轴独立、嵌套逐轴覆盖；下潜变体 Row/Column/Container/Scrollable/MouseArea/Overlay/Grid；修复 ui-gallery VM 臂全屏 demo 塌缩（Fill 失锚于 T-12 Shrink scroll/justify-center 让渡列高）②my-auto/m-auto 垂直安全居中——expand_margin_y_auto 把定高无 overflow 列内携带子展开为 h-full justify-center 包裹列（iced 缺 margin-auto 原语，CSS safe-center 对齐）；滚动列不展开。双入口接线 render_dynamic_view(path 空=根)+into_iced 三根点，幂等。T-12 不退役（与 Screen→Fixed 组合成立,P663-D1）。非目标:h-full 不重写(P663-D3)、多子项 my-auto 非精确(P663-D4)。
