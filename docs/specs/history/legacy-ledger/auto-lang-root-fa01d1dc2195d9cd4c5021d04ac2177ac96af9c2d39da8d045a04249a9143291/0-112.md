## Original content

裸 use db 语义从全量平铺收紧为仅命名空间（Rust 2018 风格）：平铺真源头定案为 Linker dep 模块 exports 裸名注册（非 TypeStore merge）——收紧三层：Linker add_entry_module（入口独占裸名；dep 限定注册 db#sym+点分别名 db.sym；删 strip-prefix 平铺后门）+TypeStore bare 不 merge/modules 注册表+native/widget 注册去 bare 通配；use db: * 显式平铺+pre-parse 快照式冲突检测（规避 parser 写共享 store 污染，同名异源异定义报错含双模块名，re-export 同定义不报）；codegen wildcard→import_scope 限定 reloc 映射；传递 bare 隔离（探针 G 断言）；a2r bare 发射 use crate::X; 无 glob；a2py 验证即目标语义零改动；use.py/use.rs/use.c 边界显式不触碰。迁移面：quickstart 16 文件具名+playground 4 例具名清单（12-todo 传递 status_text 显式化），仓内测试夹具零迁移面（三档全量绿构造性证据）。
