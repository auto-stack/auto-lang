## Original content

契约=docs/specs/stdlib/design/assembly-manifest.md「公共面契约覆盖完整性（PLAN-755）」节：公共层（.at pub 面）每个 resolved+bound 符号必须在 NativeInterface::production() 最终身份声明有独立适配契约且 signature_matches 逐字核对；缺声明与漂移（inventory 按 Rust 栈载荷推导返回 int 而公共面为 Response）都是缺陷；句柄类返回按公共身份声明（显式身份最后落位，覆盖 inventory 推导与 merge 撤销语义）。新增公共 native 必须同步补契约并附覆盖对账表。常驻守卫=plan755_http_public_face_contract_coverage 走查 + plan755_http_contracts_survive_cffi_merge。resolved-but-unbound 属 shim 缺口走 PROVIDER_CLAIM_NO_CALLEE 分诊不在契约侧补。交付：production() 尾部 +46 条声明（41 缺契约含 upload_receive/commit/reject 与 response_redirect，5 条 ok 族漂移覆盖）+ declare_generic_method_contract_identity（RequestBuilder.json[T]）。
