## Original content

New 2-D visual contract: one accepted static PNG per 2-D leaf or reserved-slot template (8-bit RGB/RGBA, sides 1..=2048, <=16MiB decoded, no APNG/interlace/palette, structural admission before any decoder allocation); integer pixel frame plus UV-only horizontal flip that never changes the entity box; autographics.sprites2d/1 (number 109, profile 20) over the unchanged triggers2d surface with ag_sprite_frame/ag_sprite_slot/ag_sprite_bound at 1 shared credit and 32 writes per callback; a per-Run fixed block re-validated against the frozen target table, registry identity and instance generations (named codes 41-44); scene-5 persistence with strict legacy rejection; and the shared 8-identity/32MiB/64MiB budgets. Canonical target is authoritative; G09 content, sound/HUD, 3-D textures and node animation remain separate plans.
