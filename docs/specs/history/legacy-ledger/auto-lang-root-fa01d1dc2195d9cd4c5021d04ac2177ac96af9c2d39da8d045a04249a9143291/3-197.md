.at 元件 remote-frame{url, class}:url=bridge WS 端点(?token=..&app=..;订阅名=url query app 参数,缺省 remote-frame,与 web 消费面 canvas_embed_web appName 同源),url 即身份(变化=断旧建新,迟到帧随旧客户端 Drop 丢弃)。宿主数据叶(window_thumbnail 同族)——帧不进 VM 状态,iced 渲染臂直读进程级 remote_frame_registry(ui/iced/remote_frame_registry.rs)最新帧槽;生命周期=租约法(渲染臂 note 续租 2s,退场=Client Drop→WsEnd Drop shutdown+join 确定性回收);重连=30s 预算/50ms 节流(ReconnectPolicy 语义内联),预算尽 Exhausted 占位终态,EOF 清残帧。双轨产物:web=透传 div(data-remote-frame/data-remote-frame-url);VM=canvas RemoteFramePainter(draw=DisplayList 等比 fit+居中直绘/相位占位;update=指针三件 bounds 局部等比换算→InputMsg 直发,不经 View 消息面)。帧节奏=ServiceTick 400ms 拍+keepalive(standalone 经 remote_frame_tick 条件拉起,退场回落)。验收=单测 8 例+e2e scripts/remote_frame_e2e.py 11/11(首帧/输入闭环/断连占位/重连恢复)。键盘 char 通道 v1 未实现(合同 §5.3 可选);musk 集成归 PLAN-102 T-04。
