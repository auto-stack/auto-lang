PLAN-708 S 档 + PLAN-711 M 档交付（auto-lang ui 域，canonical=ui/architecture.md ADR-19/24/26 + vm/architecture.md ADR-23 + 本设计文档）：【S 档】memo 三态门（env=0 强制关>1 强制开>prop；outlet 缺省 on）+宿主 UI epoch+Degrade 诊断+WidgetRegistry 进程级缓存（冷构建 365ms/27ms/1ms/2ms，原始 10-30s 消除）。【711 M 档】①CPU 可续跑片：DriveBudget 双档（片 4ms 墙钟/1M 指令天花板/64 步查钟；10M 跨片累计护栏挂 AutoTask），预算耗尽 slice 档=Runnable（栈完整可续跑）、legacy 档=真错误——静默假成功缺陷除名；②Init demand 登记簿：渲染期只登记（判定≠完成），同代际去重/身份变化=新代际+一次取消（凭据映射清理），props 快照重播种（统一根态交错等价），派发泵 FIFO 依赖序+五态观察；③帧通知泵：listen_raw 条件订阅+8ms 轮次有界泵（就绪集 FIFO 快照本轮不重拾），tick 泵退回纯 I/O；④骨架/失败占位（Loading…/可诊断错误，不无限 Loading）；⑤computed 残面：outlet 扫描穿入 MemoBlock/Conditional（DataTable memo 生效）、memo_slots_fp 不可展开槽标记回退+dyn_deps 防护（FileTree 破恒 FILL）。实测：711-runtime.md（泵占用 4160 轮 p50=p95=max=4ms≪50ms 门禁；长 CPU 20 样本；两病灶页 HIT 序列）。未实施（proposed 保持）：§7 worker 线程边界（另立 Plan；通道语义已单执行者先行验证）。【PLAN-762 T 档，2026-10-11】测试载体完成态驱动契约：drive_scheduler_to_quiescence 的 progressed 判据只认派发/完成、不计"续跑片让出未完成"（cpu.slices_run 缺位）——多片 Init 单调用不保证收敛（761 tt 批量档 gallery 四路由 flake 在案）。测试载体必须完成态+有界截止时间循环驱动（无排队 demand/在途 CPU/I/O 凭据才放行断言；超时红带 pending/CPU/I/O 诊断；precedent plan502/PLAN-759 T-08），续体在途不提前验收、不以单轮无 completed 推断完成；生产帧泵（poll_frame_pump）不受影响（每帧重入天然推进让出片）。机制钉子 plan437_child_init_tests::child_init_multi_slice_early_exit_and_completion_driving；归因 reports/762-chart-init-attribution.md；helper 判据本体修复挂 KNOWN-DEBT D-762-1（须另行授权）。
