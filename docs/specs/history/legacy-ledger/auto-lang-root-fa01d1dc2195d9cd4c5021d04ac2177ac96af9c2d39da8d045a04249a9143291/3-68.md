上限+snap 排除+layout 节点尺寸=panel 矩形,content 锚面板原点）。
D2 convert_side_panel:side/direction prop→Edge 映射（缺省 right,非法值日志落缺省）;
chrome 横条 w-96 h-full/纵条 w-full,drawer 竖向圆角+把手（bottom 首子/top 末子）;
minted_dismiss_msg 可关闭族同 dialog。
D3 split_children 子标签族:三员 trigger/content kebab/snake/连写全形态+styled 子臂镜像
dialog（sheet/drawer header/title/description/footer/close）;hovercard 不设子臂。
D4 hovercard:铸造 enter/leave;MouseArea×Popover 实测正常**未启用降级**（click-toggle
切换点在案）。
D5 rust 轨:角色表+dismissable 扩 sheet/drawer;side_panel_emission 同串发射表;
hover_card_role+generate_hover_card_popover。

+漂移 baseline +98/-18（vb 维度,533 dialog 同型）。
