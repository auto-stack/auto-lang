## Original content

PLAN-870:r2 delivers the mn (ac-mir-native) native lowering for the shared MIR's av.data/1 pure-value records and av.owned/1 text/text-record subset: frozen layouts (Str field 12B/align8, declaration order, iterative DFS), the mn private call ABI (text pairs, record by-address, hidden record out-param, MutRet write-back via field-move), the flat-memory ownership discipline (dead slot = zeroed pointer; all-exit sweeps by last-owning-write DESC with record fields in declaration order), the ac_text_runtime surface (ABI-C, negative returns trap 70), the three-tier ledger observation ruling (alloc byte-sequence exact / free multiset+exactly-once / per-instruction frees exact; within-exit order compared only on non-clone rows), the named rejection surface (wide scalars, collections/closures/dynamic, Unit, entry shape), and the conditional textlib cache axis keeping scalar manifests byte-identical. Frontend escalation picks the narrowest compiling profile (scalar/record/text-record) so B* sources keep av.core-i32/1 identity.

PLAN-889 current delta: Old generic emitter still rejects collections; explicit889 consumer admits its documented source-derived subset. New collection all-frame cleanup does not claim historical owned-profile repair.
