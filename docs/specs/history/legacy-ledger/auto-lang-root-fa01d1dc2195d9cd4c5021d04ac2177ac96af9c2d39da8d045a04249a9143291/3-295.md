## Original content

One snapshot/root lock/single entry commit verifies GLB plus exact source closure; scripts8file/2MiB quota, reserved Windows aliases, residual/pending/old-revision recovery and accepted-byte SaveAs.

PLAN-004: the closure also carries accepted static PNG payloads beside GLB under the same 8-identity/32MiB/64MiB budget; scene5 binds a per-2-D-leaf visual (asset, integer frame, flip) while schemas1-4 reject the field and non-glb resources, and disk readback covers both formats.
PLAN-005 adds a separate bounded textured scene6 profile while preserving restrictive legacy GLB and PNG rules, unchanged resource quotas, entry-last storage and complete dependency readback.

PLAN-006:r2 adds the explicit finite node-animation3d/1 domain, packed consume-once action snapshot and atomic visual pose at1 credit each, original animated closures and deterministic same-frame sampling; old static/sprite/behavior profiles retain their rules. See node-animation-and-facing.md.

PLAN-012:r1 adds explicit audio2d/audio3d profiles and scene7 bounded audio/cue closures, accepted-only native one-shot playback and complete shared CPU ownership/predecode admission with unchanged legacy limits/prices. See public-audio.md.

PLAN-013:r1 adds scene8 with the audited Lilita One font identity, exact embedded OFL/RFN license, four unique HUD slots and the 7-identity/263372-byte raw closure beside unchanged legacy quotas and entry-last storage. See public-hud.md.
