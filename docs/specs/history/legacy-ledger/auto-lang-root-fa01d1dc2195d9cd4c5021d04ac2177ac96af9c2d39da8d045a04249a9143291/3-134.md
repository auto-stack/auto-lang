## Original content

PLAN-707 交付（Design 33 阶段 C2a）：外部 HTTP/SSE 流统一资源表 http_stream::STREAMS——打开=同步登记 Opening 后向固定共享 runtime（与 705 非流式 executor 同 runtime）提交可 abort 生产者，独立许可对 AUTO_HTTP_STREAM_ACTIVE(16)/QUEUE(32) 不占非流式配额；有界队列 ≤16 条×256KiB 队满背压停读（不丢数据不无界增长）；typed pull Data/Pending/Opening/Eof/Failed，EOF 先排空队列，终态单次迁移幂等，迟到生产者禁止重建。取消=终结状态机+abort（queued/active/retry 三阶段下一 await 生效）+插入后复查闭合竞态——闭合 705「取消只删结果槽不停止执行体」缺口（async-http-result-lifecycle SD-02 修订：JOB_ABORTS 登记随完成/取消双路径出表；detached submit_detached_client_job 显式分离不受误杀）。等待凭据 ParkedWait::HttpStream+CALL_NAT rewind 重试协议（挂起臂回推迭代器 id、就绪出口清凭据——热循环根因）；generator 等待凭据化（enable→检查→await 双通道，gate 关闭驱动计数静态）。增量 SSE decoder（sse/decoder.rs）：BOM/跨 chunk UTF-8 carry/LF·CRLF·CR（悬置 CR 判别）/首冒号恰一空格/NUL id/空 data 不分发/EOF 丢未闭合/256KiB 预算；legacy parser 差异矩阵钉住。资源组：RequestScope.resources（finalize_scope 逐流取消）+ AutoTask.owned_stream_ids 第二线（generator 首 pull 在 SSE serve 循环）+级联（下游断连→上游连接真实关闭 ≤8s E2E 观测）。for 三形态：内联/变量（codegen stream_vars 分流）/生成器体（shim_iterator_next 惰性消费臂）+Generator 臂前置分流修复 DashMap 跨驱动写锁自死锁。声明面：http.at/vm.at + catalog Http.* 别名（修复流族 VM 轨静默 no-op）；sse_close/sse_error 新面；sse_get_stream 经 legacy 通道桥语义逐字节保留。顺手修复：成功 job AbortHandle 慢性泄漏。canonical：docs/specs/stdlib/design/http-stream-lifecycle.md（SD-01 新建）；SD-02 修订 async-http-result-lifecycle（取消实停）；SD-03 修订 http-handler-async-lifecycle（外部流延伸节+非目标更新）；SD-04 修订 http-server §8.1 行+§11.4 现状标注+探针清单；SD-05 修订 backend-assembly http/sse 行（后台差异明示）；SD-06 修订 networking-stdlib C2a 标注。回归：plan707 族 31 例+E2E 真 TCP 三例+tf 全量 no-fail-fast 5703/5709（5 红基线定责零因果）。
