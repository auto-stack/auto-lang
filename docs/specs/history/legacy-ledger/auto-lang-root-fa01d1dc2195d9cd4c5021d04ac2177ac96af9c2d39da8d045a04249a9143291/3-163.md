## Original content

PLAN-729 交付落账（canonical 唯源=docs/specs/stdlib/design/http-server-files.md）。新 FileResponse 公共面（http.file_response(root, rel, options) 零 I/O 描述符；严格 options：content_type/download_name/disposition/etag 强验证器，mtime+len 永不冒充强 ETag）；协议子集（GET 200/Accept-Ranges/零字节不变 1；HEAD 同表示 metadata 忽略 Range；单区间 206/416 bytes */len/未知单位畸形多区间忽略→200；前置条件 If-Match>If-Unmodified-Since>If-None-Match>If-Modified-Since 先于 Range；If-Range 强 etag/日期形态）；受限根目录打开（词法校验拒 ../绝对/drive/UNC/NUL/DOS 设备名 + 逐段 no-follow walk 检出 junction/symlink + Windows 终段 OPEN_REPARSE_POINT + 同句柄 metadata/seek/read 钉住表示）；配额与收口（active 4/queue 16/64KiB 读驱动块 ≤2 在途/fs_ops 4/prepare 30s/idle watchdog 60s 独立计时/env AUTO_HTTP_FILE_*；排队零句柄零缓冲，队满即时 503+Retry-After；恰一次收口 finish hook）；错误映射（404 缺失非普通文件/403 越界链接设备权限/500 坏 options 内部/503 队满超时）；支持矩阵（VM+生成 Rust ✅/TS Response ✅/Tauri+back_proxy 明确拒绝/legacy 500 诊断/Server.static 占位）；版本无关 FileReply 单源投影（axum 0.7/0.8 两代消费端）。
