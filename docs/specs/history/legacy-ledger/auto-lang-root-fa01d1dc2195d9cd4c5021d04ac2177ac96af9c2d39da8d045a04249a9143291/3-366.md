# Legacy Spec: Language structure closure: run bridging single source, stdlib domain assembly, call_inner shape families, Rust pipeline topic modules

## Original content

Limited structural closure keeping the crate/member granularity, default features, dependencies and ABI (873 no-split ruling stands). Four single-source responsibilities: (1) entry/run_bridge.rs holds the one isomorphic bridge run_on_dedicated_thread(code, capture, path, deadline, input) behind every public run entry variant; the G4 ExecutionEngine selector and the G5 staged typed-trap channel stay deliberately separate (StagedRunFailure + LAST_RUN_TRAP_CODE taken inside the worker closure before join). (2) vm/ffi/stdlib shell 8183->2278 lines with algorithms/state moved to 13 domain files (5 new: request_root/storage/exit_audit/http_async/rust_stdlib_dispatch); register_stdlib_ffi is now 19 ordered domain helper calls preserving statement order and the six-step production() binding sequence (872 DISTINGUISH intact). (3) call_inner's 25-segment if-let chain audited per top-level early-return, then split into 22 shape families under trans/rust/call_emit/* with explicit CallShape{Miss,Handled} tri-state (no Ok(()) overloading), last family unconditional, first-match order and the `call` outer transaction order (Vec -> UTF-8 -> positional args -> core reference -> single write_all) preserved; three audited-dead blocks kept verbatim (884-N4). (4) trans/rust.rs 7783->4293 orchestration-only lines + 9 topic modules (new post_fixes/ast_scans/merged_fixes); collect_fn_spec_params and collect_fn_str_params de-duplicated to one copy used by both pipelines, collect_fn_param_types intentionally still split (merge-mut collection divergence = 884-N1). Fingerprint closure extended in both stdlib_assembly loader chain and manifest provider_inputs(Vm) with a permanent coverage guard (plan884_provider_input_coverage). Behaviour conserved: public API surface, run results/stdout/meta, typed trap classification, error classes, 872 binding table and a2r golden bytes; no performance claim is made.
