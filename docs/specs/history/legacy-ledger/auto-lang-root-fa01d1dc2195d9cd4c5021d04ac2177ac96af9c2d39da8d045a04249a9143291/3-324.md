## Original content

PLAN-856:r1 adds a finite 2D editing viewport, bounded world-aligned grid, navigation and optional world-origin snapping. Drawing, picking, group outlines and Auto drags use the same presented transform. Edit state and accepted content remain separated.

PLAN-857:r1 adds the finite 3D editing viewport: bounded View3d (target ±65536, distance [0.5,4096], pitch [-85°,85°], ortho height [1/8,8192]) with orbit/pan/zoom, focus/reset and perspective/orthographic toggle that preserves the target and matches visible height; default/reset reuse the original sample_camera values. Picking, outlines, handles and perspective axis drags use the actual presented camera with a ray-plane drag plane; near-parallel/degenerate geometry disables handles or rejects samples keeping the last valid candidate. The XZ ground grid at y=0 is bounded auxiliary drawing (≤128 lines/1024 vertices, 1/2/5×10^k spacing) with real depth occlusion on the same device, metered separately from immutable meshes; grid off uploads nothing and default pixels equal the frozen 856 baseline. Canonical Spec is authoritative; runtime game cameras and production I2/I3 remain pending.
