## Original content

子进程执行唯一设施（零依赖 std-only，777 man-ecosystem）：argv/cwd/env/stdio 策略/退出具名分类/deadline/cancel 收尸/reader 真停/树退出（Windows Job 挂起入树；Unix 进程组=负 PGID 组信号，killpg 语义，根退出不撤销组，ESRCH=组空收尾成功）。interrupt()=Unix 显式向 owned 组转发 SIGINT/Windows 控制台 no-op；spawn_detached（daemon 分离+flags 透传+非 Windows 非零=InvalidSpec）与 terminate 原语（进程级标志，CREATE_NEW_PROCESS_GROUP 重启用）。任何返回路径不带活自有线程；写端准入先于线程； PipesHeld/ReaderIo/ReaderPanicked 具名。I-TOOL 客户端真实子进程+协议帧消费，无工具实现静态链接；发现序 env→workspace→邻接安装，缺件/版本/能力/收尾失败具名拒绝。永久回归=exec_lifecycle+plan816_cli_driver（真停/握手自退/组送达/持有者三态）+te-child 全模式。
