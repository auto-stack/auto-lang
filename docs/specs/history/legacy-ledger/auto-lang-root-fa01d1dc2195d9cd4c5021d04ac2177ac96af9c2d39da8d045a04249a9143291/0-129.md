PLAN-729 交付：服务端文件下载以普通 api.at FileResponse 返回面覆盖 VM 默认 HTTP 与生成 Rust/Axum 服务（同一执行代码：a2r-std server_file 描述符+纯协议决策单源；auto-lang http_file_service 宿主执行=受限打开/准入/有界 pump/idle watchdog/恰一次收口，版本无关 FileReply 投影 axum 0.7/0.8）；VM 编组（ApiBody::File+声明返回类型门+shim 9936+HEAD 两遍路由+405+scope 代持两期限交接）；trans lowering+类型映射+api_gen 主/委派文件分支（诊断不落模板）+api targets（axum Response/TS Response/Tauri Unsupported）+back_proxy 501；golden 32_plan729+VM e2e 15 测（基本/12MiB hash/Range/条件/路径安全/方法+int 门/async/download_name/health/路径替换/auth+open 计数/半关闭/配额/断连/727 五态互通）+生成服务实编 e2e（真实产物 cargo build+wire+12MiB+async）。债务 P729-D1..D5（shutdown drain wire/legacy wire 档/端口重绑/排队取消直接观测/权限 wire）。证据：reports/729-server-files-{decision,protocol,lifecycle,parity,verification}.md。
