债册 medium 清偿批四件全 delivered。①UICache 生成器指纹（SD-01→runtime/overview.md）：build.rs hash src/ui_gen/** 入缓存键，不匹配整缓存失效重签，VERSION 1→2——692 W-1 根修，实机三轮回归绿。②VM bus.subscribe 真运行面（SD-02→http-server.md §8.1）：EVENT_BUS broadcast::channel(256) 镜像生成 events.rs+转发线程+AsyncHttpStream 臂（案①进程内 iterator 注册表）；POST publisher 臂 publish_post_broadcast 双 serve 循环插桩（Typing/New{Type} 对齐 api_gen，has_sse 门控经 record_api_return_type 新侧信道，unique_name 防 s-expr 倾泻）；017 全环 SSE 帧与 Axum 逐字节一致+带外 POST typing UI 渲染指示。③submenu 浮动终态（SD-03→menubar-family.md）：翻案 T-11——真因=iced 0.14 官方嵌套协议（overlay::Nested 递归 Overlay::overlay 钩子）未实现；Panel 钩子+RightTop 浮动恢复，内联降为 AUTO_MENU_SUBMENU_INLINE=1 降级路径。④desktop 端点配对（SD-04→ui/overview.md）：子进程 daemon（库形态被 winit Windows 单事件循环结构性否决 RecreationAttempt）spawn_desktop_daemon 孵化 auto rqhost --pipe autodesk-rqhost-desktop-<pid>+AUTO_DESKTOP_ENDPOINT env 发布；003 exe 全环 adopt→开窗→v2 帧→EOF 回收→末窗自退。债册 P693-D2/P695-D2/P696-D1+P692 候选#1 销号；P698-D1（浮动像素确认被 D5 阻塞+交互细节）/P698-D2（daemon 生命周期无级联+launch 面接线）在册。
