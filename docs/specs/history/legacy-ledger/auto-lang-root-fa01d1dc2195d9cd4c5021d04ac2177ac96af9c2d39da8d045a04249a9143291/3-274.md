## Original content

公共 ABI 域 autoabi（win-x64 v0.1-candidate）：descriptor/3 调用前边界——出参列表（三出参聚合/handle 出参归属/callback ctx 车道/record const-mut-out 一等形态，C provider 描述与独立 header 原型逐项对照）；三腿真实 COFF 互调（AutoABI↔AutoABI、AutoABI→cl.exe C、C caller→AutoABI 含嵌套）；对象缓存=cl -showIncludes 观测依赖闭包+候选位置全集适用域（三元组派生含 ../ 父逃逸、信封版本入代际键）+命中零编译重验；两阶段精确内存预算门（fpath 记忆化共享子图完整展开路径）；正式父路径 P95<1000ms 双硬门（落盘完成后 span 口径、一请求一原始行）。实现 experimental/auto-abi-probe（独立 workspace，不进产品图）；774 ABI-A–E 分域无兼容关系。
