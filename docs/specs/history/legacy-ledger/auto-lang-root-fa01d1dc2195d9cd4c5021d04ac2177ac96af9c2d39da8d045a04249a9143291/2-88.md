## Original content

recipe 作用域从单编译单元扩展为跨包消费：依赖包 `pub style` 导出，宿主 `use <dep>.<module>: <name>` 命名/glob（只导 pub）导入，与 widget/fn/store use 同构零新语法；非 pub 命名导入与双源撞名为编译错误；传递收集（visited 防环，v1 不校验中间 pub）；「预导入通道」实现（parse 前预注册避 parser 符号钩子，parse 后 clear+source 标记受控重放），VM/Vue 四注册点同函数族单点，desugar 单点与双端同源不变。示范 examples/ui/stylekit + 045-style-import。

PLAN-637 增补（rollout 规范）：examples/ui/stylekit 为 canonical 共享配方库（hint/caption/input_field/icon_base/pill 族），33 rollout demo 全量配方化+语义 token 化；已完成 demo 禁新增裸调色板色（scripts/style_palette_guard.py + manifest 豁免表，四类口径：显式品牌色/装饰性插画渐变/语义状态 registry 无键/图像叠字恒白）；已知限制：括号形属性配方引用 VM 原生轨不支持、475 包 use 块与顶层 stylekit use 解析互斥——暂留字面量待框架收敛。
