## Original content

PLAN-687 供料 auto-edit PLAN-007 §10-5（用户裁定上游修复路线：借 Rust std 实现，未来再自研）。①read_text_range 双轨（VM shim stdlib.rs + a2r-std fs.rs，P670-D1 byte-identical 纪律延续）从 fs::read 全文+切片改 File seek+精确窗读 [offset-3,end+1)（metadata 总长；IO O(limit)）；流式语义收窄=UTF-8 校验限块区（非法字节所在块读取时报 total:-1，未读区不提前暴露）；边界回退改窗内续字节 walk（0xC0 掩码）。②code_editor_load_file(key,path) 装载端点（save 直写 want 的对偶）：native std::fs 单趟读+core.set_text 单次重写+delta 即 drain-弃+last_external 不触；返回总字节（None=缺席/IO 错/无效 UTF-8）。③a2r 映射补齐：ui_gen 增 code_editor_edit/load_file（i32）+trans File 表增 read_text_range（facade re-export 同步补）。坑：nat id 无守卫（P673-D2）——9907 撞 Env.track 错派发，改 9908。canonical=docs/design/autoui/editor-kernel.md §5.2 PLAN-687 节。
