## Original content

PLAN-732 delivered。裁定四件：①零模型扩展——[[inner]] 语义复用 autodown-core 既有 attr "wikilink"（flatten_inlines 补读 attrs：style.link 补齐+LinkInterval 随 BlockBuf 快照口径），autodown-core/auto-down 仓零改动。②命中区=DocLayout.links 单 layout-run 段矩形（push_link_regions 选区同路字节→像素；折行逐段独立命中、整块矩形禁用）。③完整点击门在 core handle_input（widget 两鼠标臂 DocInput 汇聚点，生产共一实现）：按下登记三重身份+单击节律+无修饰键、4px 拖动容差、抬起同区间才激活；rebuild/FocusLost/非左键清除。④载荷与 origin——激活构造处单点归一（首个 # 拆分 trim、无锚空串）；绑定双形态 on "open-wiki-link"（完整 kebab，jade Vue 同名）/onopenwikilink；Typed args 双 Str 经 encode/decode_payload 过 Send 边界（499 M2 先例）直达 handler 形参无 update 层拦截；origin=结构性实例绑定（per-View-node LinkCallback，无全局 last-mounted 单槽）。预存事实注记：autodown_editor_sync 首帧槽位缺席 no-op（生产次帧重降层补内容）。
