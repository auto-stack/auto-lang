## Original content

inproc VM App 拉起零宿主退出=桌面日用底线，宿主消失必须可归因。P694-D1「静默退出×3」勘定外因结案：机器级内核/驱动不稳定（三日三蓝屏 0x9F/0x1A/0xA+GPU TDR 族；走查窗口 System Event 6008=09-23 10:59:12 非正常关机实锤），蓝屏吞进程=无 panic/无 WER 应用崩溃，签名逐项吻合；嫌疑 back-proxy lazy-start/media 供给/inproc panic 边界经 15 轮复现矩阵（基线窗口化×5+全屏×2+禁A×2+禁B×2+他App×2 零死亡、A/B 面点火实证 port 3358）+WER 零宿主崩溃记录三重排除。契约三件：①观测面=宿主必须留足迹（[ui-desktop] start/alive 30s/exit+panic 钩子带 backtrace，examples/ui_desktop.rs；CLI 路径 rust_ui.rs X9 同形制）+死亡判位表（exit 行在场=正常/心跳截断无 WER=外力对时 6008/心跳截断+WER 1000=内部崩溃）；②对照缝=AUTO_NO_BACK_PROXY（整体旁路供给）/AUTO_NO_NATIVE_MEDIA（旁路②capability 臂）（back_provision.rs，勘定器械生产零影响）；③勘定方法=repro_host_exit.py+事件日志三查。归因档案 docs/plans/reports/p697-stability/attribution.md。
