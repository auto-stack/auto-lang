## Original content

Actual CompositionInput focuses one canvas, excludes panel input and clears held/parity/debt on cancellation. Starting cancellation persists through complete initialization into Paused until explicit Resume.

PLAN-855:r1 preserves public Host/Play/Editor APIs, single state and ownership, accepted publication, input/cancellation/Stop, resources and old behavior/1..5 profiles while organizing Host into private commands/panel/play_adapter/viewport impls. CLI/probe/current455-source closure locations are explicit. Canonical target is authoritative; M2/S0 complete, new M2 capabilities and production I2/I3 pending.

PLAN-856:r1 adds a finite 2D editing viewport, bounded world-aligned grid, navigation and optional world-origin snapping. Drawing, picking, group outlines and Auto drags use the same presented transform. Edit state and accepted content remain separated. Canonical Spec is authoritative; 3D navigation and production I2/I3 remain pending.

PLAN-857:r1 moves 3D editing picking/handles/axis drags to the actual presented perspective/orthographic camera (union-OBB pick, NDC 0..1 finite rays, closest-t with stable-ID ties; clipped or invalid-w groups yield no handles). Axis drags freeze the world origin/axis/presented matrices and use a camera-derived drag plane; degenerate or near-parallel cases disable the handle or reject the sample keeping the last valid candidate. Snap/half-step away-from-zero, single capture, cancel and stale-view rejection rules remain; the 2D viewport and original reset tolerances are unchanged.
