PLAN-528 W12/W13→530→533 的 overlay 家族收编收官批：dialog 已由 533 T5 落地,本计划收敛为
**sheet/drawer/hovercard 三员**并补齐首版遗漏的 **Rust 代码gen 轨**（533 先例=每 overlay 成员
需解释器臂×2（D-GAP 双镜像）+rust.rs 发射双轨）。原语扩展=PopoverPlacement Edge 贴边四变体
（EdgeLeft/Right 全高、EdgeTop/Bottom 全宽,viewport 相对,snap/翻转排除）+模态 chrome 判定
单点化 `is_modal_chrome()`（Modal∪Edge* 共享 scrim+外点整吞+dismiss 语义）。执行期两处隐含
前置补齐:parser 铸造机器角色表扩 sheet/drawer（gallery 页无显式 open 靠铸造 toggle 开合）、
Edge 面板 layout 节点尺寸取全高/全宽矩形（命中/绘制域）。债 P534-D1..D6（delay 不消费/
无拖拽/vue 对照未运行/avatar 家族缺口/gallery 导航栈溢出存量/未降级裁定）。
