## Original content

官方默认集（blueprints/ 磁盘目录=策展集）扩至 13 包：存量 4（login/note-list/note-editor/sidebar-nav，仅 login 增 two_column 变体）+ PLAN-640 新 9（form/{signup,settings,wizard}、data-display/{data-table-crud 双变体,master-detail}、feedback/{empty-state 三分法三变体,result-page}、navigation/sidebar-shell（app 壳，与 sidebar-nav 内容互补）、dashboard/overview（palette 不含 chart——PLAN-484 注册退役实证，图表面走 extension_point charts EDIT region，DEBT 在账））。新包=六字段契约示范集（props/actions/dataSource/extension_points/acceptance 非空）+ gotchas 三反例（首条通用反例=dataSource 不烧死包内）。官方默认集判定标准五条成文（docs/specs/blueprint/project.md）：①跨 app 频率/业界锚点 ②契约非平凡 ③palette⊆WidgetRegistry 双端可发射 ④状态机≥三态 ⑤NL spec 可被 agent 组装——新包准入门槛。kind 词表（contract.md Q5）=form/navigation/dashboard/data-display/feedback/editor/layout/composite（8 种，对齐磁盘）+ 治理规则（新增 kind 须随 spec 沉淀并同步 gallery kindOrder）。gallery 自动化：examples/bps-gallery/src/bps.ts 改 Vite import.meta.glob 磁盘派生（零手写零生成物，取代 Plan 343 export-gallery-meta 展望——避免生成物同步面），build-bps-gallery.yml CI 门禁（paths 含 blueprints/**，frozen-lockfile）。已知限制（KNOWN-DEBT §已知限制 640 行）：L1 点号 use 通道对连字符 bp key 不可达（resolve_module_path 无连字符变体，8/13 包受影响；绕开=bind 工件或 L2 拷贝）。
