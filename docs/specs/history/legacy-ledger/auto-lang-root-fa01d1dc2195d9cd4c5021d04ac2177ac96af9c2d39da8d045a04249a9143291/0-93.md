## Original content

C ABI 双面全通（auto-term 004 §5⑤⑥ 清账）：⑤导出面=#[export]/#[export(system)] 兄弟包装模块发射（#[unsafe(no_mangle)] pub extern C/system，符号=fn 名、调用方零改动；int i64↔i32 边界 cast、cstr CString 边界（空指针容错/内嵌 NUL 降级不 panic 穿越 FFI）、句柄（具名 *T）空安全解引用 &mut+缓冲（标量/void 指向）双形参规则；auto_cabi_kit 生成模块收口全部 unsafe——004 §3.5 原则）；⑥use.c 双形态下降（manifest 共享 IR 增 link 字段 serde 默认 static：S 静态 #[link] extern 块+安全包装+缓冲助手 / D 动态 libloading OnceLock，解析序 env <LIB>_DLL→exe 同目录→PATH；source_dir 解析管线接入测试/门/CLI 三入口）。三级 CFACE_OK 实证：AC-03 引擎 12 符号 Auto 版 cdylib（005 语料，包真 PtySession）被 597 a2c 驱动器链接（dumpbin /exports 12/12 符号集恒等）；AC-04 ⑥ S 驱动链真 autoterm_core.dll.lib；AC-05 同一驱动产物改链 ⑤ 产物=Auto↔Auto 全链零手写胶水（import lib 内嵌 DLL 名换引擎）；AC-06 D 形态运行期加载。执行期关键修正：Plan 376 P2 .get().expect() 误注入 unwrap（expect 入安全方法表）、*void→*mut c_void、外来非 Clone 字段 derive 压制（显式 #[allow]）。
