# ASE 原生页签定时生命周期

## 适用范围

PLAN-1109 为 Gallery ASG-09 提供独立数字钟样例。Windows x64 原生宿主可在同一窗口打开 Clock 和 Counter，各自保留业务会话。数字钟样例在 `experimental/ase-m0/fixtures/clock/main.at`，取材于 AutoUI 012 的墙钟采样行为。AutoUI PLAN-105 负责完整的 012 应用。ASG-09 的其他应用与 checkpoint 行为由各自的交付验证。

## 可见时间源

- 显式注册的 Clock 接收 `Tick(int)`。样本为 UTC 日内秒 `0..86399`。普通 Node handler 格式化 `HH:MM:SS`，持久状态和帧文本来自受检 AV 会话。初始帧文本读取同一已挂载程序。
- 选中时在下一次宿主步进采样。UI 在首个合法样本前显示加载态。后续唤醒由单调时钟按一秒调度，从处理时间重新计算截止点，积压的周期合并为一次最新采样。真实墙钟允许前后跳动和跨午夜。
- 单窗口持有至多一个活跃注册和一个待处理唤醒槽。唤醒标记包含会话 ID、会话代次、可见代次和截止点。受理与派发核对活跃标记，派发同时核对实际选中车道。重选同页保留截止点。
- 隐藏或关闭会先失效并撤销待处理工作。隐藏保留 AV 状态根，恢复用新可见代次及新墙钟样本；关闭释放显示车道和 AV 根，重开时重新初始化。采样失败或越界不派发业务事件，下一合法样本可恢复。

更新与输入在同一宿主事件循环串行执行。原生选择、显示和输入仍由选中车道管理。窗体最小化策略、通用后台计时、HTTP 服务和 Gallery 默认入口由其他交付处理。

验收输入、实际命令、版本及归档证据见 [PLAN-1109](../../plans/archive/1109-ase-clock-tab-lifecycle.md)。AV 运行时合同见 [组件事件会话](../ace-migration/component-event-sessions.md)。
