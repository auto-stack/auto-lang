## 3. 搜索接线勘定（T-01 决策）

**决策：采用 VitePress 内建 local search（minisearch，纯前端离线索引），通过 `themeConfig.search = { provider: 'local' }` 启用；UnifiedNavbar 的搜索按钮以合成 Ctrl/Cmd+K 事件打开官方弹窗。**

已核实（本 worktree node_modules/vitepress@1.6.4 源码）：

1. `VPNavBarSearch.vue`：`provider==='local'` 时在 window 上注册 `onKeyStroke('k', ctrl/meta)` 与 `/` 热键，`showSearch=true` 渲染 `VPLocalSearchBox`。
2. `VPLocalSearchBox.vue:416`：`<Teleport to="body">` —— 弹窗传送至 body，**不受** `.VPNav { display:none }` 隐藏影响（现状 UnifiedNavbar 用 layout-top 替换 VPNav，VPNav 仅 CSS 隐藏但保持挂载）。
3. 合成事件打开法是 VitePress 官方自用模式（同文件 algolia `poll()`：`e.key='k'; e.metaKey=true; window.dispatchEvent(e)`）。SiteSearch.vue 复用同一机制，不导入 1.x 内部组件、不依赖 2.x API → 满足计划 §5.1 的版本约束（仅依赖 1.6 行为，记录于本节作回归检查项）。
4. `/` 热键对 INPUT/TEXTAREA/contentEditable 不触发（`isEditingContent`）；CodeMirror 用 contenteditable，天然豁免。Ctrl/Cmd+K 在 CodeMirror 内会打开搜索（VitePress 股票行为不检查编辑态）→ **需在主题层加捕获相 keydown 守卫**：目标在 `.cm-editor` 内时 `stopPropagation`，防抢编辑器输入（AC-02/AC-03 相关，T-02 实现）。
5. 索引范围：local search 按 locale 分库建索引，覆盖该 locale 全部渲染页面（含 ui-desktop/ui-android 等专题正文、docs、books 生成页）→ "Vue 专题正文不遗漏" 由 VitePress 内建机制保证，无需自建摘要方案。范围外（图片文字、独立 SPA `/ui/*`、Playground 全语料）确认不在索引内，符合计划边界。
6. 固定查询验收：`ownership`/`所有权`/`AutoShell` 三词在 EN/ZH 各自 locale 命中有效页面（T-02/T-07 e2e 断言）。

## 5. 语言切换与 locale fallback 勘定

事实（本 worktree 核实）：

1. **docs/books 双语 1:1**：`scripts/prepare-content.js` prepareDocs/BOOKS 将 EN 复制到 `website/docs/`，ZH 侧 `.cn.md` 优先、无译则 EN 回落复制 → `website/zh/docs/**` 与 `website/docs/**` 路径一一对应，**无 404 可能**（未译页在 ZH URL 下呈现 EN 内容 = 现有站点既定行为，保全）。
2. **手工专题页全镜像**：ai/apps(+4 子页)/autoos/blocks/charts/index/os/playground/python/rust/script-as-rust/ui-*(4)/ui/(2)/v05 均有 `zh/` 对应文件。
3. **共享 SPA**：`/ui/gallery|blocks|charts|a2ui|demos` 为独立 SPA（public/），无中文镜像，**双语同 URL**，导航标注"共享入口"。

**fallback 规则（navigation.ts 实现）**：

- EN→ZH：`/` → `/zh/`；`/x` → `/zh/x`（docs/books/专题全命中）。
- ZH→EN：`/zh/x` → `/x`；`/zh/` → `/`。
- 共享 SPA 路径：原样保留（双语同链）。
- 带 fragment：切换后保留 fragment（hash 原样拼接）；若目标页无对应标题，页面按无 fragment 打开，不造 404。
