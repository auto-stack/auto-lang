# PLAN-634 T-01 归因报告：terminal_pixel 像素金样环境漂移

结论先行：**漂移维度 = 渲染环境态（wgpu 适配器/MSAA 合成 × 系统字体栅格）的
时间性翻转，非代码回归**。逐字节金样比对把这张环境敏感面钉进了门禁——这是
015 收尾 2 红的根因。634 落地的修复是**比对策略稳健化**（§5 方案 b）：语义
契约改由环境无关断言承担（墨水占比/容差差分/同进程字节确定性），金样降级为
留档 + 告警制审计，门禁在全部探针环境下 3/3 绿。

## 1. 挂账事实（015 收尾移交）

- terminal_pixel selection/cursor 两金样在 200% DPI 桌面持续 2 红；
- bisect 定案非代码：f0dc16732（晨绿点）洁净 worktree 复红，跨树复现；
- 同日晨绿午后红 → 漂移是**时间性环境态**，不是提交内容。

## 2. 渲染管线的环境敏感面（代码层证据）

headless 管线 = `iced_test::simulator` → iced_wgpu（MSAA×4）→ cosmic-text：

| 敏感面 | 证据 | 漂移表现 |
|---|---|---|
| wgpu 适配器/后端枚举 | `iced_wgpu::Renderer::name()` 恒返 `"wgpu"`（lib.rs:969-971）——**后端翻转不换金样后缀**，直接字节不匹配红 | 帧整体微差（AA/合成路径） |
| MSAA×4 resolve | headless 截屏固定 `Antialiasing::MSAAx4`（iced_wgpu lib.rs:963） | 边缘若干灰阶抖动 |
| 系统字体栅格 | 文本经 cosmic-text 系统 fontdb（`Family::Monospace` 同解析路径用于 `cell_w()` 实测与行段落），字形栅格随字体集/字体缓存状态变 | 字形级大面积差 |
| ToDesk/远程会话、显示设置 | 虚拟显示驱动改变适配器枚举；DWM/驱动状态影响合成——015 期漂移时间线与之吻合 | 同上任一 |

## 4. 漂移维度定案

1. **非代码**（015 bisect + 634 全探针金样零漂移双证）；
2. **非后端字符串可枚举**（vulkan/dx12/gl 全绿，§3）；
3. **定性为环境态翻转**：适配器枚举/MSAA 合成路径 × 系统字体栅格，
   触发源候选=远程会话虚拟显示、驱动/DWM 状态、字体集变更（§2 表）；
4. **逐字节金样对该漂移类结构性脆弱**：同一 `-wgpu` 后缀下字节面可翻转
   而渲染语义（文本层/高亮层/光标层入像素）不变——门禁应断言语义，
   不应断言环境。

## 5. 修复落地（方案 b：比对策略稳健化）

`crates/auto-lang/src/ui/iced/terminal_pixel_tests.rs` 重写（T-01/D1）：

- **硬门禁（环境无关语义）**：
  1. bounds 不变；
  2. 基线墨水占比 > 0.05%（实测 0.153%，缺文本 ≈0.018%，3× 分离度）；
  3. 同进程双渲染**逐字节一致**（确定性噪声基线；同环境同适配器，字节级
     恒成立，环境翻转不破）；
  4. selection/cursor frame vs base 容差差分 > 0.1%（实测 0.212%，层缺失
     ≈0.036%，2× 分离度；负验证已跑：注掉选中层 → 红，还原 → 绿）。
- **金样降级为留档+审计**：首跑自建不变；其后按容差比对，超 5% 预算仅
  eprintln 告警并附再生成配方（不再 red 门禁）。
- **再生成配方（受控流程）**：删除
  `crates/auto-lang/test/ui/terminal_pixel/terminal_pixel_<name>_<kind>-*.png`
  → 重跑本测试即按当前环境自建；随后跑
  `cargo test -p auto-lang --features ui-iced,iced-layout-tests --lib
  terminal_pixel_dump_golden_stats -- --ignored --nocapture` 印证
  （墨水/差分应复现 §3 校准表量级）。
- 新增 dev-dep：`png = "0.18"`（随 iced_test 同版本，不新增编译单元）。

## 6. 复现配方状态

本计划执行期内无确定性复红配方（漂移需环境态翻转，当前机器处于绿态）。
替代保障：新门禁对全部已探针环境（默认 + 三后端）绿，且对漂移类
（字体替换/适配器翻转/MSAA 抖动）按构造免疫；若未来复红，属金样审计
告警，不阻塞门禁——这正是本修复要消除的假阳性通道。
