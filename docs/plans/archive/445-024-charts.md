## M1 落地记录（2026-08-25）

- **形态**: 单 App widget；左数据面板（类型按钮组 + 系列色块/checkbox/统计串）+ 右图表区（四类型 `if .chartType` 分支渲染 SVG 直通）。
- **几何策略**: **Init 一次算全四类**，类型切换/系列开关全部单行 handler（零重算）——模块级 fn 不进 vue SFC（§0.6.E-3）、handler 间无法互调，M1 取"算全 + view 分支"。
- **§0.6.H 落地验证**: donut 为末月构成、**循环累进角度 `math.cos/sin/round` 直调**（gallery donut 手算常量直线形态的通用化）——49%/32%/19% 精确渲染。
- **验收**: strict 再生 exit 0；vue-tsc 零错；vite 构建绿；四类型截图视觉验收全过（line 双线/bar 6 组双柱 Feb 305 最高/area 半透明填充+描边/donut 完整三色环+图例）。
- **踩坑记录**: ① 转译器局部变量与 model 字段同名时误发 `.value`（局部 `labels` × model `labels`）→ 应用层改名 `axisLabels` 规避（445 边界不改 crates；生成器缺陷记债务）。② `--gen-only` 不铺组件脚手架，首次需全量 `auto build -r vue`（生成+安装+构建一次过）。
- **M1 简化（SPEC 已记录）**: 刻度对全系列取 max（隐藏不 rescale）；donut 忽略可见性（plan §6）。

## M2 落地记录（2026-08-25）

- **机制**: `.Tick` 通用（`aura/extract.rs:630`——`.Tick` handler + model `interval` int（被取走作 setInterval 周期）+ 可选 `running` str 门控 `watch(running)` 启停，vue.rs:3228）。012-stopwatch 即此机制，非专用特判。
- **数据点**: 纯整数算术锯齿波 `150+(tickN*37)%120` 等——**刻意避开 f64 值入 record**（vmax 的 int 比较链对 f64-tag 值未验证，整数保平安；f64 波形留 M3 vm 轨验证后再议）。
- **滑窗**: first-flag 重建模式（`over = len >= windowLen`，首个被跳过后 push 新点）——无索引切片，全部已验证构造。
- **UI**: Play/Pause（running 门控）+ 窗口 8/12/20 按钮组 + 说明文字；流式驱动 line/bar/area 重算（与 Init 同式第二份内联——§0.6.E-3），donut 保持静态构成。
- **验收**: strict 再生 + vue-tsc 零错 + vite 绿；流式视觉验证（临时去 running 门控令 onMounted 即启，virtual-time-budget 12s ≈ 30 ticks）：窗口滑动（Jan..Jun 尽出、t19..t30 在窗）、锯齿波形、Pause 红 + 12 高亮——**全对**。恢复门控后 watch(running) 发射确认。
- **性能基线（vue 轨）**: 400ms 间隔下 JS 侧重算（~3×窗口长度次字符串拼接/系列）+ Vue 响应式 path 属性更新——headless 观察 30 ticks 无丢帧/无累积迟滞；vue 轨**远未触及性能边界**。**svgdoc 序列化路径的裁决数据（VM 轨）留 M3 实测**——v1/v2 canvas 的裁决不在 vue 轨上做。
- **踩坑追加**: ① `running` 注释掉（悬空 `.running`）时 view 的 `if .running == "true"` 竟渲染 Pause 分支——生成器对悬空 ref 的兜底行为，M3 前不动（恢复门控后无影响），记档。② .Tick handler 体被内联进 setInterval 回调（generate_handler_body），循环/if 转译与 Init 同路径，无新风险面。

## 1. 目标

**图表工坊**：编辑数据 → 切换图表类型 → 观察渲染的交互式 demo，AutoOS 系统监视器/图表应用的孵化形态。钉住：

- **模型驱动数据系列**：系列增删/颜色/可见性开关 → path 重算（响应式链路）。
- **类型切换**：line / bar / area / donut 四类同数据切换（几何模式来自 gallery 已验证实现）。
- **流式更新**：`.Tick` 追加数据点 + 窗口滑动（012 先例）——**svgdoc 高频重绘的性能试金石**（437 v1 SVG/v2 canvas 分层的裁决数据源）。
- **双后端**：vue + vm 实机（038 惯例）。

## M3 落地记录（2026-08-25，进行中）

- **实机链路打通（三根修，全量 3666 绿 + 实机验证）**：
  1. **GET_ELEM 无 GenericInstanceData 分支**（engine.rs）——vm_bridge 把 model 字面量物化为 GenericInstanceData（非 ObjectData），`d[field]` 在 vm 运行时恒 0；补镜像分支（按名查 field_names → fields，Value 分发与 RC 契约同 ObjectData 臂）。实机验证：barD/statsD/labels/donut 全对。
  2. **数组字面量 last_expr_type 残留**（codegen.rs，真凶）——`var out = []` 编译后残留**前一表达式**的 last_expr_type（f-string 的 String）→ store 推断把 out 记成 StrFixed(0) → `out.push` 按 `str.push(178)`（应 list.push=101）解析而**静默失效** → 滑窗重建列表恒空 → `.monthly` 空 → vmax=0 → bar 段 `510/nn` **DivisionByZero 中止**（ASH_DEBUG_VM_LOG=1 实锤；bisect 的"随机"成败全由 `[]` 前一条语句的类型决定）。修复：① Expr::Array 编译后置 last_expr_type=Array；② 空数组推断默认动态 List（与 state 字段合成语义对齐）。
  3. **复现载具升级**：VmBridge::new（AuraWidget 路径）**无法**复现实机失败——全保真单测 `plan445_m3_slide_window_rebuild`（WidgetDecl 解析 + new_from_decls + call_handler_for，与 dynamic.rs on_with_input_for 逐步一致）秒级复现并钉死。
- **实机验证（修复后）**：monthly 稳定 12 点滑窗、t 系列标签滚动、完整 lineD 路径、**零 handler 错误**——VM 轨流式全链路通。
- **`.Tick` 语义（Plan 402）**：VM 轨 handler 无条件派发、handler 自决（038 模式）；vue 轨 setInterval 级门控——**跨轨语义分歧**，应用层需在 handler 内查 running（024 待补）。
- **svgdoc 动态 props（已落地）**：`d: .lineD` 绑定经 `resolve_expr_to_string_with`（state 读取 + loop 绑定）解析进 SVG 文档——字面量走同一解析器行为不变。单测 `plan445_m3_svgdoc_dynamic_props` 钉死序列化格式；**实机视觉验收通过**（vm 窗口蓝/绿锯齿折线 + t 标签）。此前记录的"冻窗"经对照复测为**环境级偶发**（单线程测试与后续多次实机均稳定），非本改动所致。
- **`.Tick` running 门控（已落地）**：handler 内 `if .running == "true"` 自决（Plan 402 语义，038 模式），与 vue 轨 setInterval 门控对齐。实机验证：running=false 时 tickN 稳 0（18s+），Play 后按 400ms 流动。
- **desktop_mcp.py（17/17 绿）**：038 harness 模式（Popen + AUTOUI_MCP_PORT + autoui_* 工具）。覆盖：初始态/四类型切换/系列 toggle（checkbox 用 action="toggle"）/流式 Play→ticks→滑窗 t 标签/Pause 停止；**墙钟速率实测 2.49/s**（400ms 标称——早前测得的 5/s 为 MCP 查询延迟伪影，墙钟法纠正）。含启动重试（≤3 次，窗口环境级 MCP 起始 flake）与调用级瞬断重试。
- **golden 入库**：`tests/golden/donut_legend.txt`（确定性：desktop 49%/mobile 32%/tablet 19%）逐字节对比；`stream_perf_sample.txt` 记录式（速率/滑窗标签随时刻变化，只入档+格式校验）。
- **性能数据（VM 轨 svgdoc v1 裁决输入）**：400ms tick 下实机稳定 2.49/s 重绘，handler+view 重建在 MCP 查询延迟（~1.5s/次，含全量 view 材料化）之下无积压。**结论：024-charts 的 12 点窗口规模下 v1 SVG 直通完全够用；v2 canvas 桥接的触发条件应基于更大窗口/更高频（如 16ms/百点级）的重测**，本次数据不足以触发提前立项。
