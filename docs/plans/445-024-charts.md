## M1 落地记录（2026-08-25）

- **形态**: 单 App widget；左数据面板（类型按钮组 + 系列色块/checkbox/统计串）+ 右图表区（四类型 `if .chartType` 分支渲染 SVG 直通）。
- **几何策略**: **Init 一次算全四类**，类型切换/系列开关全部单行 handler（零重算）——模块级 fn 不进 vue SFC（§0.6.E-3）、handler 间无法互调，M1 取"算全 + view 分支"。
- **§0.6.H 落地验证**: donut 为末月构成、**循环累进角度 `math.cos/sin/round` 直调**（gallery donut 手算常量直线形态的通用化）——49%/32%/19% 精确渲染。
- **验收**: strict 再生 exit 0；vue-tsc 零错；vite 构建绿；四类型截图视觉验收全过（line 双线/bar 6 组双柱 Feb 305 最高/area 半透明填充+描边/donut 完整三色环+图例）。
- **踩坑记录**: ① 转译器局部变量与 model 字段同名时误发 `.value`（局部 `labels` × model `labels`）→ 应用层改名 `axisLabels` 规避（445 边界不改 crates；生成器缺陷记债务）。② `--gen-only` 不铺组件脚手架，首次需全量 `auto build -r vue`（生成+安装+构建一次过）。
- **M1 简化（SPEC 已记录）**: 刻度对全系列取 max（隐藏不 rescale）；donut 忽略可见性（plan §6）。

## M2 落地记录（2026-08-25）

- **机制**: `.Tick` 通用（`aura/extract.rs:630`——`.Tick` handler + model `interval` int（被取走作 setInterval 周期）+ 可选 `running` str 门控 `watch(running)` 启停，vue.rs:3228）。012-stopwatch 即此机制，非专用特判。
- **数据点**: 纯整数算术锯齿波 `150+(tickN*37)%120` 等——**刻意避开 f64 值入 record**（vmax 的 int 比较链对 f64-tag 值未验证，整数保平安；f64 波形留 M3 vm 轨验证后再议）。
- **滑窗**: first-flag 重建模式（`over = len >= windowLen`，首个被跳过后 push 新点）——无索引切片，全部已验证构造。
- **UI**: Play/Pause（running 门控）+ 窗口 8/12/20 按钮组 + 说明文字；流式驱动 line/bar/area 重算（与 Init 同式第二份内联——§0.6.E-3），donut 保持静态构成。
- **验收**: strict 再生 + vue-tsc 零错 + vite 绿；流式视觉验证（临时去 running 门控令 onMounted 即启，virtual-time-budget 12s ≈ 30 ticks）：窗口滑动（Jan..Jun 尽出、t19..t30 在窗）、锯齿波形、Pause 红 + 12 高亮——**全对**。恢复门控后 watch(running) 发射确认。
- **性能基线（vue 轨）**: 400ms 间隔下 JS 侧重算（~3×窗口长度次字符串拼接/系列）+ Vue 响应式 path 属性更新——headless 观察 30 ticks 无丢帧/无累积迟滞；vue 轨**远未触及性能边界**。**svgdoc 序列化路径的裁决数据（VM 轨）留 M3 实测**——v1/v2 canvas 的裁决不在 vue 轨上做。
- **踩坑追加**: ① `running` 注释掉（悬空 `.running`）时 view 的 `if .running == "true"` 竟渲染 Pause 分支——生成器对悬空 ref 的兜底行为，M3 前不动（恢复门控后无影响），记档。② .Tick handler 体被内联进 setInterval 回调（generate_handler_body），循环/if 转译与 Init 同路径，无新风险面。

## 1. 目标

**图表工坊**：编辑数据 → 切换图表类型 → 观察渲染的交互式 demo，AutoOS 系统监视器/图表应用的孵化形态。钉住：

- **模型驱动数据系列**：系列增删/颜色/可见性开关 → path 重算（响应式链路）。
- **类型切换**：line / bar / area / donut 四类同数据切换（几何模式来自 gallery 已验证实现）。
- **流式更新**：`.Tick` 追加数据点 + 窗口滑动（012 先例）——**svgdoc 高频重绘的性能试金石**（437 v1 SVG/v2 canvas 分层的裁决数据源）。
- **双后端**：vue + vm 实机（038 惯例）。

## 2. 现状盘点（2026-08-24）

## 3. Phase 划分

### M1 — 应用骨架（vue 先行）
- `examples/ui/024-charts/` 脚手架：pac.at（`render: "vue"` 起步，front_port 4024）+ SPEC.md（025 的 SPEC 模式）。
- 布局：左侧数据面板（系列列表：名称/颜色块/可见性 checkbox/数值区）+ 右侧图表区（类型切换 tabs + 主图）。
- 四类图渲染函数（gallery 模式内联：line/bar/area/donut 的 path 生成）。
- 类型切换与系列开关驱动 path 重算（handler 更新 model）。

### M2 — 流式更新（.Tick）
- 播放/暂停 + 窗口长度调节；`.Tick` 追数据点、滑出旧点。
- **性能记录**：tick 间隔下的重绘表现写回本计划（svgdoc 序列化路径的裁决依据——不达标即触发 437 v2 canvas 桥接提前立项）。

### M3 — vm 实机 + 测试
- `auto run --render vm` 实机（038 双后端惯例）；暗色模式对齐（Design 19）。
- `tests/desktop_mcp.py`（013 惯例）：类型切换断言、系列开关断言、流式数据变化断言。
- 386 golden：vm 端 draw list / svgdoc 导出样例入库（对齐 413 §7.6 编辑器先例）。
