## 1. 目标与平台缺口

一个**图表工坊**应用：编辑数据系列 → 实时切换图表类型 → 观察渲染。它钉住：

- **模型驱动数据系列**：`model` 里的数据结构 → chart props 的绑定路径（现有 charts-gallery 是静态数据，没钉这条）。
- **交互**：hover/tooltip（ChartTooltip）、图例开关系列、类型切换（line/bar/area/donut）。
- **流式更新**：`.Tick` 驱动的实时曲线（追加数据点 + 窗口滑动）。
- **vm 端自绘图表**（核心价值）：RenderCommand 目前只有 quad/text/image/clip/layer（见 [Plan 413 §7.6](413-cross-platform-code-editor.md)），折线/面积/坐标轴需要 thin-quad 旋转模拟或新增 shape 原语——这是 golden 三件套的**矢量件**。

## 2. 现状盘点（2026-08-23 立项时已核实）

- vue 端图表 widget 族**已注册**：AreaChart/BarChart/LineChart/Chart/ChartTooltip/ChartLegend（`crates/auto-lang/src/ui_gen/widget/registry.rs:3199-3283`，Data 类）；charts-gallery 单文件示例钉住 vue 端可用。
- vm/iced 端**无**任何图表渲染路径。
- `.Tick` 定时器机制已有（012-stopwatch 先例）。

## 3. Phase 划分

### M1 — vue 端应用壳（无 crates 改动）
- `examples/ui/024-charts/` 脚手架：pac.at（`render: "vue"`, front_port 4024）+ src/front/app.at + SPEC.md（025 的 SPEC 模式）。
- 数据面板（系列列表：名称/颜色/可见开关/数值编辑）+ 图表面板（类型切换 tabs + 主图）+ ChartTooltip/ChartLegend 接线。
- `.Tick` 流式模式：暂停/恢复 + 窗口长度调节。
- `tests/desktop_mcp.py`（013 惯例）：类型切换断言、系列开关断言、tooltip 出现断言。

### M2 — vm 端自绘（crates 热区，本计划拥有渲染原语）
- 设计决策：折线/面积走 **rotated thin-quad 序列**（不动协议）还是**新增 Polyline/Fill 命令**（动协议，需对齐 386 的设计输入与 Stage 1 裁决）。倾向先 quad 序列打通，协议扩展单列后续项。
- iced 端图表渲染器：坐标轴刻度（text 原语）、网格线、数据几何（quad）、图例、hover 十字线。
- `auto run --render vm` 与 vue 端视觉对齐（截图对比，038 惯例）。
- pac `render` 切换为双后端可跑。
