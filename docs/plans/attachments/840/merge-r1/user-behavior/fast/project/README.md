# Move

Run `autographics-authoring --open <this-directory>/scene.agscene --behavior main.at`.
Choose Run, focus either canvas and use arrows/V. Stop restores the editing scene.
Edit only main.at, then Stop/Run to see a new source snapshot without rebuilding.

Copy this directory, including assets, anywhere on a regular local disk. Relative
main.at resolves against scene.agscene, independently of the process directory.
The bundled two-part GLB is original MIT-licensed PLAN-838 test geometry.
See ../../../api/README.md for signatures, limits and Save As/source boundaries.
