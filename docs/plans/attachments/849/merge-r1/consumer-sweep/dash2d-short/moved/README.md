# dash2d

Open scene.agscene, choose project default, Run; focus the 2D canvas and use Left/Right. Each input tick requests a 100-unit dash. Auto sweeps the fixed all-mesh AABB, then stops short by user clearance. Change speed/clearance in the bound Auto source, Update, Save and reopen. Initial overlap/contact shows a blocked state with zero movement; this sample does not resolve penetration. Pause/Step/Resume/Stop use the existing controls.
