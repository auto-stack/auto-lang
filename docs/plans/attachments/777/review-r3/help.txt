usage: modularity-audit.py [-h] [--root ROOT] [--config CONFIG]
                           [--baseline BASELINE] [--mode {observe,strict}]
                           [--output OUTPUT] [--refresh-baseline]
                           [--no-cargo-check] [--self-test]

v0.6 模块边界基线与增量检查（只读审计；Category A，不编译不写输入）

options:
  -h, --help            show this help message and exit
  --root ROOT           扫描根（默认：脚本所在仓根）
  --config CONFIG       边界配置路径（默认 <root>/.autoos/module-boundaries.toml）
  --baseline BASELINE   冻结基线路径（默认 <root>/.autoos/ 配置声明）
  --mode {observe,strict}
                        observe=全仓观察（默认）；strict=冻结基线增量判红
  --output OUTPUT       报告输出路径（默认 '-' = stdout）
  --refresh-baseline    在干净受管树上生成/刷新冻结基线（写入配置声明的基线路径）
  --no-cargo-check      跳过 cargo metadata --locked 一致性对照
  --self-test           对 test/fixtures/modularity/audit/ 运行 V-01..V-04 正反控自测
