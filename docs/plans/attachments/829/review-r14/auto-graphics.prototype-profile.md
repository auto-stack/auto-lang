# auto-graphics — prototype profile

## Supported surface (validated)

- Window (winit 0.30) + offscreen RGBA8-sRGB targets on one wgpu 27.0.1
  device/queue; minimize suspends presentation; resize reconfigures only the
  target.
- 2D: ortho quads/circles, alpha blend, fontdue text (33 px Breakout HUD,
  32 px squash HUD).
- 3D: ortho/perspective cameras (0..1 z), depth, lit meshes, 2048²
  directional shadow mapping, untextured GLB (gltf 1.4) with node-transform
  baking, procedural environment.
- Audio: kira/cpal; one-shot SFX + looping streams.
- Fixed-step clocks: 1/60 s (Breakout), 1/120 s (squash physics);
  deterministic replay from frozen action streams + seeds (bit-exact vs
  independent references).

## Resource/update/lifecycle contracts

- Object/resource identity is session-scoped with generations; stale/reused
  ids are rejected; late cross-session events are rejected.
- Bounded identity-keyed caches: unchanged resources are never re-uploaded
  (created-counter flat after warm; measured uploads/frame 0 for 3D).
- Local edits touch only named objects (touch-set + revision tracking).
- Failure taxonomy: zero_size_target, missing_file, bad_shader,
  bad_model_parse, stale_identity, cache_full, resource_released,
  surface_lost; failures never clobber the last-good frame.
- Restart/close: 20× restarts baseline-stable per game with the REAL game
  resources integrated (GLB mesh store flat after build, looping audio
  surviving retries, per-session cache); view add/remove is witness-derived
  (a forgotten target fails the gate); close-during-load awaits an abort
  callback acknowledgement; teardown facts are sampled AFTER device
  destruction. AGP spawns no owned worker threads for the runtime; the iced
  spike's input fallbacks use short-lived helper threads (recorded).

## Replay/measurement method

- Canonical replays: frozen streams + seeds in `testdata/`; golden traces
  generated by independent references; replay compared within frozen
  tolerances (positions 1e-3 / 1e-2; events exact).
- Metrics: CPU wall around sim+encode+submit, P50/P95, cold/warm, two
  views; GPU timing UNAVAILABLE (no timestamp queries) — must be stated,
  never fabricated. Raw reports under `scratch/829/`.
- Verifier: gates assert on independent state (event recount, hashes,
  device tokens, session ids); a skipped gate is a failure (sabotage
  demonstration recorded).

## Profile differences (known, not replicated)

Gamepad/right-mouse inputs, Bevy stepping tool, gl_compatibility branch,
production AutoUI. No cross-platform or competitor performance claims.
