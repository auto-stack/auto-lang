## 1. 内核 rope 化（单写者版）

- **诉求**：`CodeEditorCore`（`crates/auto-lang/src/ui/code_editor/core/mod.rs`）
  文档缓冲从行数组形态迁到 rope + 摘要（叶存文本块，节点缓存长度/行数/
  点-偏移换算，O(log n) 编辑与定位）。
- **明确不要的**：协作基因——无 OT/CRDT/多编辑流合并。**单写者模型**：
  主线程写，后台任务（解析/搜索/diff/保存）只读快照隔离。copy-on-write
  的动机仅为快照，非多人并发。
- **动机（预算门控）**：auto-edit 战略 §2.1 解锁条件列——100 MB 文本
  打开 ≤1 s、1 GB 可打开（分块/mmap）、大文件满帧滚动、空闲内存 ≤60 MB，
  在 rope 前架构性不可达（已裁定：rope 前禁对该路径调优）。
- **验收形态建议**：缓冲编辑 API 复杂度文档化（编辑/定位 O(log n)）；
  100 MB 文本打开+滚动冒烟可跑；现有 code_editor_* 内建语义零回归
  （auto-edit 矩阵为下游验收面）。

## 2. 统一 delta 协议（编辑事件增量化）

- **诉求**：code_editor 编辑事件从"整文本回读"改为**区间增量**（delta）：
  人击键、agent 结构化写（区间替换/插入/删除）、undo/redo 走同一条增量
  事件流——人与 agent 的写在内核层无差别。
- **现象（下游现状证据）**：auto-edit `specs/auto-edit/src/front/editor_store.at`
  五处以 `code_editor_text(key)` 全量回读维护 `.tabs[i].src` 字符串镜像
  （CtxCut/ActUndo/ActRedo/ActCut/ActPaste，约 L229/350/359/376/391）；
  每击键级操作复制全文，对大文件是结构性死罪。
- **期望形态**：`code_editor_delta(key) -> {start,end,replacement}` 事件
  或等价订阅面；配套 agent 结构化写端点（见 §3 同期的 back 面扩容）。
  auto-edit 侧 store 去文本化（PLAN-005 候选）以本项为前置。

## 3. back 分块读端点

- **诉求**：`read_text` 之外增加分块读（`offset`/`limit`，可选编码参数
  面——初期仅 UTF-8）。大文件模式下 front 不"拥有"全文，视口拉取。
- **证据**：auto-edit `specs/auto-edit/src/back/api.at` 现为整串交付
  （`read_text` 直通 `File.read_text`）；vue/split 轨 ts_adapter 生成

## 4. F-R1：a2r server 生成器双缺口（perf 模式 a2r 段硬阻塞）

- **现象**：`auto run --server rust`（a2r axum 后端）编译失败——
  ① server 生成器模板硬编码 `use api::Db` 状态注入（013 形态固化）→
  无 Db 类型的契约编译 E0432；② 契约 fn 转译为空体桩（实现体不随转译）。
- **证据**：auto-edit `specs/auto-edit/README.md:101-104`（rust 引擎暂
  不可用注记）；`docs/plans/archived/003-auto-edit-frontback-dualtrack.md`
  F-R1 定性段（约 L223 起）。
- **影响**：auto-edit perf 模式（战略 §5 L2 阶梯 = a2r+release+RQ）中
  split 形态不可用；**merged 形态（perf 主路径）不受此阻**——`auto run
  -r rust -q` 为进程内直调。修复优先级低于 §1/§2，但 L 线被驱动协议
  （HTTP 面）依赖它。
- **期望形态**：模板去掉 Db 假设（无状态契约可生成）；契约 fn 实现体
  随转译（或明确的实现挂接点）。

## 6. RQ 渲染臂覆盖缺口：`codeeditor` 不在 native_queue_set（2026-09-21 T-06 新登记）

- **现象**：`auto run -r vm -q`（VM+RQ 形态）实例即退——VM UI native-queue
  臂按「拒绝渲染，禁静默错绘」语义报
  `native queue 臂视图未覆盖: tag:codeeditor` 后退出；rqhost 侧对应
  `adoption 未达 Active（预算耗尽弃置）`。
- **根因**：`crates/auto-lang/src/ui/desktop_protocol/coverage.rs`
  `Coverage::native_queue_set()` 现集 = text/button/input/textarea/
  checkbox/radio/slider/select/image/progress/popover/mousearea/
  windowthumbnail/workspacepreview 等基础 kind——**codeeditor 不在列**
  （tree/menubar 族等复杂 kind 推测同缺，coverage 判据可自动列出全集）。
- **影响**：auto-edit 的 L1 结构探针（VM+RQ）与 L2 性能模式整链被阻
  （编辑器核心 widget 即 codeeditor）；perf.py 已按特征分类
  blocked-on-upstream（exit 3）。
- **期望形态**：native_queue_set 增补 codeeditor（及其余实测扫描出的
  kind），VM+RQ 达 Active 可渲染；下游以 `perf.py smoke` exit 0 复验。
