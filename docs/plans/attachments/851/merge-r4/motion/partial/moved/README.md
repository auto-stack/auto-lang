# corridor3d

Open scene.agscene, select API v5 and project default, Run. Focus the 3D canvas and use arrows. Right requests a diagonal world displacement; the perpendicular input adjusts its tangent. Auto computes at most two contacts with explicit clearance. The marker reports node/status and the second marker origin/normal. Pause/Step/Resume/Stop retain their existing behavior. Change speed/clearance in Auto, Update, SaveAs and reopen. This is fixed AABB motion, not gravity or penetration recovery. The 3D project retains the frozen eccentric multi-part GLB and parent/static transforms.
