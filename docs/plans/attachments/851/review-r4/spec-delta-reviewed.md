## SD-01 add docs/specs/auto-graphics/bounded-motion-profile.md

Explicit autographics.behavior/5 selects MotionV5/profile11. ag_move_and_slide(node,visible_only,dx,dy,dz,clearance) is fixed-AABB world displacement, not velocity. Legal same-Run positive/zero ordinal leaf, finite D, 2D dz0, visible_only0/1, finite clearance>0. Static mover offsets and actual current world box need positive widths on active axes; shape failure is InvalidMotionShape15. Target degeneracy is allowed. All-mesh Descriptor/static TRyRxS and original visibility policy remain; actor visibility is irrelevant.

Auto alone computes at most two directional slab scans and one final actual-local+parent admission scan. All matching target geometry is validated on first scan before pruning or a normal overlap state. No native Rust motion kernel, extra graph, candidate array, cross-callback cache, recursion, third contact or queued remainder. First scan may fuse strict initial overlap with complete geometry validation. Subsequent scans may skip already-validated unchanged static geometry and delay later-axis arithmetic on a proven separating axis. Skipped arithmetic creates no error; executed nonfinite remains a sticky fault.

Initial strict overlap returns InitialOverlap3, no local move, contacts0, lowest ordinal node and normal0. Initial closed boundary may leave or move along the face; this exception applies only when the origin is on the whole box boundary. An origin outside the box that later reaches a tangent/endpoint closed contact still blocks. Nearest f32 t / lowest ordinal / entering-axis X/Y/Z tie order; +/-0 and positive t underflow retain the original distinctions. Public cast/sweep keep their original closed initial-contact semantics.

For each hit use a=abs(D on normal axis), safe_t=0 when clearance>=t*a, otherwise t-clearance/a. Advance D*safe_t; remaining D*(1-safe_t), project only the inward normal component to0. Rebuild virtual local and actual f32 local+parent world before the next scan. First hit can slide; second hit advances safely then terminates ContactLimit2 even if remaining projection is0. No-hit request is Free0; one blocked hit is Clipped1 (including ordinary clearance-imposed zero advancement).

Final candidate is checked against every matching target for strict expanded-box interior, and for finite/positive candidate world widths. Finite unacceptable rounding or attempted nonzero advancement that cannot change actual world (and cannot yield accepted tangent progress) returns PrecisionStop4: restore action-start local/world, contacts0/node-1/normal0/delta0/unapplied=request. This does not hide invalid geometry/parameters, nonfinite arithmetic, configuration, CPU or credits. A tiny f32 skin advance rounded to0 can meet this rule at a corner; zero-by-clearance itself remains normal clipping. No epsilon changes boolean/tie decisions.

One normal leaf publication changes its local once and updates its row in the original worlds array using the same local+parent order. A fixed publication marker lets v5 derive consume an already-coherent leaf without re-deriving all nodes. V5 leaf setters can likewise synchronize a clean axis when its parent axis is already valid; group/visibility/already-dirty axes retain original dirty propagation. Final original whole-frame validation is still the only external publication boundary; callback fault closes the VM and preserves last-good. Subsequent explicit setters are permitted and do not mutate the stored result snapshot.

Getters ag_motion_status/contacts/node(token), ag_motion_origin/delta/unapplied/normal(token,axis). Origin is actual final world, delta actual final-start, unapplied requested-actual (not next-tick queue); last blocker node/axis normal; Free node-1/normal0; 2D z0. Motion24, result getter1, original cast8/sweep16/AABB1, total32. Attempts invalidate latest token before charging/checking. One typed latest slot and positive monotonic Run sequence, no internal scan token/credit issuance, no wrap (14), wrong kind/stale/no/cross-callback token InvalidResult13. Begin/end/Stop invalidate; ordinary AABB leaves slot intact.

Fixed total query/sequence/kind/count/dirty state bound remains40 logical i32/f32 scalars (160 logical bytes); current measurement is29/116. NanoValues, String structures/capacity, shared map, program, stack and allocator are separately reported, not claimed as160 total SDK bytes. Original128 nodes,100000 steps/120 resumes/250ms callback,30s init/2s tick/8ms pump,256KiB user/64KiB managed/320KiB combined remain. Yields are observations, not exact instructions or a real-time guarantee.
