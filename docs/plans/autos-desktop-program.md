> **本文拥有的东西**：依赖图、入口条件仪表盘、裁定登记簿。计划内部进度不在此抄。

## 目标

一套窗口管理代码（WM 是 AutoUI App），在 Win/Mac 上是单 OS 窗口的虚拟桌面，
在 Linux 上是原生合成器宿主，在 Web/移动端是同构嵌入——设计级一致，
App 一次编写处处原生。里程碑 M0-M6 详见 Design 23 §6。
