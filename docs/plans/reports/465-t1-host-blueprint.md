# Plan 465 T1 施工图：Vue 宿主 scaffold 定案

> 2026-08-28。依据：Plan 465 §3.1 决策点 + 代码盘点（auto-man vue.rs / 463
> app_registry+shell.at / auto CLI）。正式「评审通过」由 /auto-plan:review 门禁承载。

## 1. 定案汇总

| 决策点 | 定案 | 一句话理由 |
|---|---|---|
| D1 触发命名 | **`auto run --desktop`**（Run 布尔 flag → 注入 `AUTO_DESKTOP=1` env） | 验收标准明写该形态；env 注入是既有惯例（AUTO_UI_THEME/AUTO_VM_WINDOW 同型）；tauri 管线内部先跑 vue 生成，env 天然透传 |
| D2 registry 生成器位置 | **`crates/auto-man/src/vue.rs`** 新增 host 段（扫描 + `src/apps-registry.ts` 生成 + 每 app SFC 预生成） | 与既有 scaffold 生成器同文件；复用 `auto_lang::ui::app_registry::scan_apps`（auto-man → auto-lang 依赖方向可用，app_registry.rs 注释已声明） |
| D3 shell 来源 | **宿主 App.vue = auto-man 内置模板**，taskbar/布局/overlay 结构 1:1 镜像 463 `assets/shell.at`，差异登记对拍清单（T8 执行） | 宿主需 z-stack 容器/overlay 槽/WmStore 接线，超出 DesktopShell 声明面；运行期转译引导复杂度不成比例。`taskbar` element 本身进 a2vue（T4/T6），模板消费同一 element 语义 |

## 2. D1 详述：`--desktop` flag + env 注入

- `crates/auto/src/main.rs` Run 子命令加 `#[arg(long)] desktop: bool`；
  `true` 时 `std::env::set_var("AUTO_DESKTOP", "1")`（与 §Plan 458 theme 注入同型，
  main.rs:976 起）。
- **不采用** pac `render:"desktop"`：`render:` 字段现有语义是「App 的前端形态」
  （app_registry 扫描过滤 vm/vue 用，examples/ui/*/pac.at 实值）；宿主是
  **项目级运行模式**而非前端形态，复用该字段会重载语义、污染 app 过滤。
- 消费点：`VueProject::generate()` 在 `AUTO_DESKTOP=1` 时切换 host scaffold 段
  （§4 文件清单）；`run_tauri_project`（tauri.rs L29 起）内部先跑 vue 生成，
  env 透传即得 tauri 宿主（T7 零新增触发面，tauri.conf 全屏窗口另配）。
- apps 目录来源：`--apps <dir>` flag > `AUTO_DESKTOP_APPS` env > 默认
  `<workspace-root>/examples/ui`（验收场景值）。

## 3. D2 详述：registry 生成器（T3 落地面）

- 扫描：`scan_apps(apps_dir, ScanOptions { render: Some("vue") })`——
  examples/ui 的 vue 形态 App（001/006/013/015/025…，pac `render: "vue"`）。
- 每 app 预生成：`auto_lang::ui_gen::generate_component_from_file(entry,
  opts)` → `gen/front/vue/src/apps/<id>/App.vue`（既有单文件 SFC 管线，
  router 懒加载同源 `() => import('@/pages/X.vue')` 先例）。
- 产物 `src/apps-registry.ts`（生成物，勿手改）：

  ```ts
  // generated by auto-man — build-time app registry (Plan 465 T3)
  export interface AppEntry {
    id: string; title: string; icon: string; category: string;
    load: () => Promise<Component>;
  }
  export const APPS: Record<string, AppEntry> = {
    "001-helloworld": { id: "001-helloworld", title: "Hello World",
      icon: "app-window", category: "app",
      load: () => import("./apps/001-helloworld/App.vue") },
    // … scan_apps 全量，目录名字典序
  };
  ```

  动态 import 路径全部静态字面量（vite 可分析；运行时拼路径不支持）。
- 生成时机：`generate()` / `regenerate_source_files()` 的 host 分支内每次运行
  重扫重写（App 源变更即刷新；与 index.html 每run重写惯例一致）。

## 4. 宿主 scaffold 文件清单（T3–T6 落位）

| 文件 | 性质 | 内容 |
|---|---|---|
| `index.html` | 不变 | 单 `#app` = 宿主根 |
| `src/App.vue` | **模板替换** | 宿主 shell：背景层 + z-stack 容器 + taskbar + overlay 槽（结构镜像 shell.at） |
| `src/main.ts` | 模板替换 | 宿主 bootstrap：`createApp(HostApp).mount('#app')`（无 router/i18n） |
| `src/apps-registry.ts` | 生成物 | §3 |
| `src/apps/<id>/App.vue` | 生成物 | 每 app 预生成 SFC |
| `src/wm/store.ts` | 手写模板 | `WmStore`（reactive 单例）：windows `Map<wid,{appId,title,rect,z,focused,comp}>`、layout、focusedWid、launch/close/focus/setRect |
| `src/wm/layout.ts` | 手写模板 | 463 `ui/layout.rs` TS 直译（free/grid/master-stack 纯函数 + snap 半屏几何；I6 期望值表共享） |
| `src/wm/keyboard.ts` | 手写模板 | `document` keydown 捕获段：Ctrl+Space 召唤 / Alt+Tab 轮转 / 布局切换（R12） |
| `src/wm/VirtualWindow.vue` | 手写模板（T4 起对接 a2vue 金样） | `virtual_window` DOM 叶：absolute+clip+拖拽/resize 把手+hit-test 焦点 |

不引入 pinia/vuex——模块级 `reactive` 单例即 WmStore（ChartCrosshair 命令式
`createApp().mount()` 先例证明实例级隔离成立）。

## 5. D3 详述：shell.at ↔ 宿主模板对应表（对拍清单种子）

| shell.at（iced 真源） | 宿主模板（vue） | 备注 |
|---|---|---|
| `msg SummonLauncher` | `emit('summon-launcher')` → overlay 槽开关 | 464 落地后接真 launcher |
| `msg LayoutFree/Grid/Stack` | `wm.setLayout('free'\|'grid'\|'stack')` | layout.ts 直译 |
| `__wm_wins`（宿主注入数组） | `wm.windows` reactive 数组 | 同名同形 |
| `__wm_meta`（"layout\tfocused_wid"） | `wm.layout` + `wm.focusedWid` 字段直读 | 无需字符串协议 |
| `__desktop_cmd`（"verb\targ" 总线） | 直接函数调用（`wm.close/focus/setLayout`） | vue 宿主同进程直连，无总线必要；**登记差异** |
| taskbar 按钮 ⊞/▦/≣ + 窗列按钮/× | 同布局同 class 语义（h-12 底栏） | taskbar element（aura.at:723）两端同源 |

`__desktop_cmd` 直连化是**语义级差异**（iced 因跨进程/跨语言才要字符串总线；
vue 单页内 props/事件直连即 Plan §1 非目标所述「宿主↔launcher 经 props/事件
直连」）——T8 对拍按本表核对。
