## 4. 关键一致性决定

- 机器人算法退出本轮候选/验收；AutoOS通信框架→ROS2兼容/另议机器人算法，映射调研与算法分别管理。
- 797有限互调≠DLL插件装载/热重载；798有限AV≠真实CTE或完整JIT；独立图形≠AutoUI融合；离线快照≠活体采集；生成文件≠准确论文复刻。
- 独立原型需要公开合同/可验证输出；依赖旧AST/Value/VTree/pac/build或共享manifest就必须重新核对协调面，不凭新crate身份认定无影响。
- 完整知识流程仍为v0.7主线；Linux/鸿蒙等已确认目标不降格为单demo。候选行序不是优先级。
- 本轮不更新Spec为已实现、不修改旧实现/生成物、不在其他仓写文件、不触发Cargo/docs_gen。
