# 012-clock — 现代全功能时钟应用

集传统手表 ⌚ SVG 表盘、数字时钟、世界时钟、闹钟、秒表、倒计时五大功能于一体的现代时钟应用。完美适配系统深浅色主题与 AutoUI Design Tokens。

## 功能特性

1. **时钟（Clock）**
   - 传统手表 ⌚ SVG 矢量指针表盘（外圈、12 小时刻度与 60 分钟细刻度，时/分/秒三针联动）。
   - 秒针配有运动红色/橙色点缀与延伸平衡配重。
   - 大号数字时钟（`HH:MM:SS`）与本地日期、星期显示。
   - 指针/数字双模展示。

2. **世界时钟（World Clock）**
   - 全球 8 大主要城市时间（北京、东京、悉尼、伦敦、巴黎、莫斯科、纽约、洛杉矶）。
   - 智能计算与本地时差（如 "+0小时"、"-8小时"、"昨天/今天/明天"）。
   - 昼夜状态图标指示（☀️ 白天 / 🌙 夜间）。

3. **闹钟（Alarm）**
   - 卡片式闹钟列表，支持快捷开关切换。
   - 快速时间步进器增添新闹钟。
   - 本地持久化存储（`storage`，支持多槽位与重启恢复）。

4. **秒表（Stopwatch）**
   - 大字号码表展示与毫秒分段。
   - 经典双按钮控制流（开始/停止/计圈/复位）。
   - 计圈列表，标识圈速分段与累计时间。

5. **倒计时（Timer）**
   - 常用快捷时间胶囊预设（1m/5m/10m/15m/25m/30m）。
   - 精细时/分/秒调节步进器。
   - 倒计时到期横幅通知与友好清除。

6. **桌面小组件（Desktop Widget `view mini`）**
   - 面向桌面 Dashboard 小组件面板的紧凑命名视图。
   - 精致的传统手表迷你表盘 + 数字时钟与本地日期。
